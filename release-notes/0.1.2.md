## Fixes

* Gboard no longer types or activates the last key under the finger when the finger slides off the keyboard, including Use voice typing. Gboard leaves typing to the screen reader only when its version code is at least 60105832, so SandFly's version code is now 100000000 plus the build number.
* Typing in Compose text fields no longer reads the typed word and "End of field" after each word.
* Typing no longer lags when the keyboard's spell checker doesn't answer, as with PixelBoard. The spelling suggestion hint is spoken when the spell checker answers.
* SandFly's braille keyboard types without delay in SandFly's own fields, such as the sound theme name, and deleting a word works there.
* Starting selection mode keeps a Characters, Words, Lines or Paragraphs reading control, and selects by that unit. Other reading controls still change to Characters.
* The find voice command finds text in web pages and WebViews.
