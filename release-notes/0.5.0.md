## New

* Automatic renewal (SandFly Pro): a SandFly Pro code can renew by card every month or year. Go to Settings > SandFly Pro, and choose Turn on automatic renewal. The SandFly Pro screen then shows the renewal date. To cancel automatic renewal or change the card, choose Manage subscription on the same screen. SandFly posts a notification before a renewal or an end date, and when a payment fails. To buy SandFly Pro or enter a code, go to Settings > SandFly Pro.
* SandFly overview: SandFly can show the recent apps as a list, in place of the system overview. Go to Settings > Overview, and turn on Use SandFly's overview. It needs Shizuku. The Overview command, the navigation gesture and the Recents button open the list. Double-tap an app to switch to it. The actions of an app are Close, Split screen and App info, and Delete on a physical keyboard closes the app being read. Close all and System overview are buttons at the bottom of the window. To put the most recent app last, turn on Most recent app at the bottom. To show the apps as a grid, use Columns.
* Alt+Tab: with Use SandFly's overview on, hold Alt and press Tab on a physical keyboard to move through the recent apps, and Shift+Tab to move back. SandFly says each app. Release Alt to switch to the app, or press Escape to stay in the current app.
* Previous app: switches to the app used before the app on screen. Using the Overview command again while SandFly overview is open does the same. The command is in Settings > Commands > System actions.
* System overview: opens the system overview, also with Use SandFly's overview on. The command is in Settings > Commands > System actions.
* Take screenshot: takes a screenshot. The command is in Settings > Commands > System actions.
* Split screen menu: goes to the divider and runs the actions of the divider. Choose Split screen in the SandFly menu, or assign the Split screen command in Settings > Commands > System actions.
* Open in split screen: opens an app in split screen beside the most recent other app. Choose Open in split screen in the actions of an app icon on the home screen, swipe up with three fingers in the braille app launcher, or swipe down with three fingers in the handwriting app launcher. It needs Shizuku.
* Element navigation in apps: every element command and browse mode key now works in apps as well as on web pages, including buttons, checkboxes, lists, tables, landmarks and headings of each level. SandFly scrolls to reach the next element. Apps do not report heading levels or visited links, so each heading level moves through all headings, and all links in an app count as unvisited.
* Sentences reading control: moves through text one sentence at a time. Swipe down for the next sentence and up for the previous sentence. To add the reading control, go to Settings > Reading controls.
* Reading control lists: you can make named lists of reading controls, each with Next and Previous commands. Go to Settings > Reading controls > Reading control lists, and choose Add list. The commands are in Settings > Commands > Reading control lists.
* Symbol dictionary: replaces a symbol or a sequence of symbols wherever the exact text appears, in speech and on a braille display. Go to Settings > Speech > Symbol dictionary, or Settings > Braille > Symbol dictionary, and choose Add a replacement. A replacement can be empty, which removes the symbol. Entries apply to all apps or to one app.
* Volume change feedback: plays a tone on each volume step, says the new volume, or both. Go to Settings > Volume keys > Volume change feedback, and choose Off, Tone, Speech, or Tone and speech. The default is Speech, which says the volume and the level, such as "Media volume set to 60 percent". Speech now also speaks the volume while media plays. This setting replaces Speak volume changes in Settings > Verbosity.
* Volume key long press duration: sets how long a volume key is held to run a long press command. Go to Settings > Volume keys > Volume key long press duration. Volume key commands also run on an always-on display that shows the lock screen.
* Editing menu: a menu of Clipboard history, Copy, Add to clipboard, Cut, Paste, Select all and selection mode. To use the menu, assign Editing menu in Settings > Commands > Text editing.
* Take picture and describe: takes a picture with the camera and describes it, and you can ask follow-up questions about the picture. The command is in Settings > Commands > Image and screen descriptions.
* Light level: a new mode of Live recognition, which says how much light the light sensor measures, such as Dim light or Bright light.
* Keep recognition models loaded: keeps Whisper and the on-device model in memory for 5, 15 or 30 minutes after use, so that the next recognition starts faster. Go to Settings > Typing > Dictation, or Settings > Image and screen descriptions.
* Speak item type without a pause: says the name and the type of an item with no pause between them. Go to Settings > Verbosity, and turn on Speak item type without a pause.
* Keyboard sounds: SandFly plays a sound when an on-screen keyboard opens or closes, for all on-screen keyboards. To change whether SandFly announces that the keyboard is shown or hidden, go to Settings > Verbosity > Announce keyboard shown or hidden.

## Changes

* Speak container information is now two switches in Settings > Verbosity: Speak list information, and Speak grid and table information.
* Translate last spoken phrase: in a text field, the command now translates the text of the field, except in password fields, and the cursor stays in place.
* The new volume is spoken about 0.6 seconds after the last volume key press.
* Lock screen: when the screen turns on, SandFly speaks only what is chosen in Settings > Verbosity > Screen on and off.
* Swiping past a list item taller than the screen now moves to the next item at once, in lists that support it.
* Live region text appears on a braille display with Show device messages on.
* Keep speech on the phone while casting now sends speech and sounds to a local output while Android routes them to a Wi-Fi display.
* Dictation with Android speech recognition stays in one session across pauses, on recognizers that support it.
* Granular editing opens with the split type you chose last.
* Keyboard shortcuts appear in the settings on Android TV when a physical keyboard is connected.
* EuroBraille displays: Space with dot 2, 3, 5 or 6 runs no command until assigned, so these chords can have commands different from the left joystick.
* Rows and columns is selected automatically in tables only with Switch to table navigation in tables on.
* Problem reports include the log captured when the report screen opened, and a record of main thread stalls.
* The privacy policy link opens on sandfly.dev.

## Fixes

* On-device models could not be installed, because the published model files changed. SandFly now downloads each model from a fixed version.
* Updates could fail with Could not install the update, when Android cleared the cache or GitHub returned errors. SandFly now retries the download, checks the size, and reports download failures separately.
* SandFly stopped responding on a screen where a parent item and a child item named each other as traversal before, such as in Google Messages.
* On Samsung phones with One UI, a volume key press changed the accessibility volume while speech or sounds played. The key now changes the media or ring volume.
* SandFly crashed when lift to type described a focused item without an event.
* In a physical keyboard session, focus stayed off the text field after typing removed the focused item. Focus now returns to the text field.
* Focus moved to the wrong item, or was lost, after scrolling a list or after a fling.
* In selection mode on web pages, the focused paragraph can now be selected.
* Spelling hints played repeatedly for one misspelled word while the cursor stayed on the word.
* A translation language whose download stalled could not be downloaded again.
* The first settings item was hidden under the action bar without Google Play services.
* Gesture profile Default rows did not name the command that the gesture runs without the profile.
* Scripts lost emoji in JSON text on some devices.
* In Turkish, the edit box role now says Metin alanı.
