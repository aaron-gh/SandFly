## New

* Script agent (SandFly Pro): SandFly Pro writes a script from a description of what it should do, and tests it on the phone. Open the app the script is for, go to Settings > Scripts, and choose Build a script with SandFly Pro, or use the Build a script with SandFly Pro command. When the agent needs another screen or a test, open the screen or try the script, and choose Done or Reply in the notification. The notification SandFly Pro is building a script has Reply and Stop. The script opens in the script builder under Written by SandFly Pro, with Accept, Ask for changes and Discard. Until you accept it, the script runs without the internet and Java code permissions. To change a built script, choose Change with SandFly Pro on the page of the script or in the script builder. Building a script uses much more of the monthly usage limit than an agent task. To buy SandFly Pro or enter a code, go to Settings > SandFly Pro.
* Script builder: makes a script without code. Go to Settings > Scripts > New script. A script holds rules that change items, reading controls, commands, triggers, speech changes and settings. Rules can relabel, hide or silence an item, change what SandFly says for it, read it as one item, arrange the parts that are read, change the reading order, and add actions, including each button inside the item. Record an action records a rule action as you do it in the app. In Item details, Add a rule for this item adds a rule for the inspected item. Export script saves a script as a .zip file. To change an installed script, choose Copy to script builder on its page.
* Script API version 6: rules can set what is read for an item (read), offer the buttons inside it as actions (buttonActions), hold a touch on it (touchHold) and run steps. Queries match hints, states, tooltips, regular expressions and item types. New functions are sf.macros.run, sf.touch.lock, sf.feedback.mute, sf.text, sf.device.get, sf.device.set, sf.device.media, and sf.system functions for timers, alarms, calls, messages and the camera. Script commands without their own gesture, keys, menu or reading control need no input permission. The reference is in Settings > Help & feedback > User guide, Appendix D.
* Macro recorder: the Record a macro command records the steps of a new macro as you do them: presses and long presses, scrolls, typed text, opened apps, and commands such as Back, Home and Paste. To stop, use Record a macro again, use Stop macro, or open the Recording macro steps notification. Scrolls before a press become a Repeat while step, and repeated actions become a Repeat step. To record steps into an existing macro, choose Record steps on its screen. Text typed in password fields is not recorded. The command is in Settings > Commands > Macros.
* Macros in apps and in Actions: a macro can run only in one app. Choose App on the screen of the macro, or choose Add app on the Macros screen, which lists macros by app. With Show in Actions on, the macro is in the Actions menu and the Actions reading control of each item in its app. Show in Actions only when sets a condition for the focused item.
* Macro shortcuts: to run a macro from the home screen, choose Add to home screen on the screen of the macro.
* Macro steps: Tap at position, Touch and hold item, Long-press or scroll an item, and More steps: Play sound, Vibrate, Play tone, Copy text, Open link, Open settings page, Share text, Set volume, Set ringer mode, Device setting, Media key, Set timer, Set alarm, Call, Send message, Open camera, Press keys, Show message, Set value, Fetch link and Translate text. Texts can hold values, such as {item}, {clipboard}, {time} and {battery}. New tests are Focus is inside an item and Value. Steps that find an item have Item type, and Match in has Tooltip.
* Tap, then swipe gestures: one to three taps with 2, 3 or 4 fingers, then a swipe with as many fingers, such as Double-tap, then swipe up with 2 fingers. Tap with 2 fingers, then swipe up and similar gestures swipe with one finger. They are in Settings > Gestures > Tap, then swipe, and have no command by default.
* Two-finger angle gestures: such as Swipe up then right with 2 fingers. They are in Settings > Gestures > 2 finger angle, and need Handle two-finger swipes in SandFly.
* Three-part swipes: one-finger swipes in three directions in one stroke, such as Swipe right, up, then right. They are in Settings > Gestures > Three-part swipes, and have no command by default.
* Two-stroke swipes: two one-finger swipes with the finger lifted between them, such as Swipe right, lift, then swipe up. Either swipe can be a back-and-forth or angle swipe. To turn them on, go to Settings > Gestures > Time between two-stroke swipes. The default is Off.
* Double-tap with 2 fingers, top and bottom: a two-finger double-tap with one finger in the top third of the screen and the other in the bottom third. It is in Settings > Gestures > 2 fingers.
* Shake and Quadruple tap on back: shake the phone, or tap the back of the phone four times, to run a command. Go to Settings > Gestures > Shake, or Settings > Gestures > Back tap. Shake sensitivity is under Shake.
* Touch lock: while touch is locked, touches and gestures on the screen do nothing and do not reach the app. Use the Lock or unlock touch command, in Settings > Commands > SandFly, or press both volume keys to unlock. To lock touch when the screen turns on, on the lock screen or while the proximity sensor is covered, go to Settings > Touch > Lock touch automatically. Touches while touch is locked is on the same screen. Touch lock needs Android 13 or later.
* Double tap taps the screen: in the apps you choose, activating an item taps it on the screen. Go to Settings > Touch > Double tap taps the screen. It needs Android 11 or later.
* Google Sheets: the table reading controls and commands move between the cells of the grid, and the actions of a cell include Edit cell and Insert formula.
* Stop at the last item before wrapping: with Wrap around on, the first swipe past the last or first item stops there with the end sound, and the next swipe wraps. Go to Settings > Navigation > Stop at the last item before wrapping. It is on by default.
* Wrap around in reading controls: sets whether reading controls go from the last value to the first. Go to Settings > Navigation > Wrap around in reading controls. Until you change it, it follows Wrap around.
* Focus text inside items separately: each piece of text and each state inside an item gets its own focus. Go to Settings > Navigation > Focus text inside items separately. It is off by default.
* Move from the status bar and navigation bar to other windows: a swipe past the end of a system bar moves into the app. Go to Settings > Navigation. It is off by default.
* Speak only focus moved by the user: in all apps or in the apps you choose, SandFly speaks only focus that you move. Keyboards with their own speech turns off speech of keys and typed text while a keyboard you choose is shown. Go to Settings > Verbosity > Apps with their own speech.
* Continuous copy: moves through every item after the focused item without speech, scrolling on the way, and collects the text. At the end, check the texts to copy, and choose Save. The command is in Settings > Commands > Text editing.
* Start selection and End selection: in Granular editing, Copy text from screen and Select last spoken phrase word by word, these actions select every item between two items.
* Voice effects: Speech > Voice effects adds Bass compression, Voice compression and Treble compression, and the Deep bass preset. Presets save the bands and the effects.
* None in Speak punctuation and symbols: leaves punctuation and symbols out of speech, except a character read on its own. To keep signs such as plus, minus, percent and currency signs with numbers, turn on Say symbols that change meaning. Go to Settings > Verbosity > Speak punctuation and symbols.
* Repeat last spoken phrase slower: says the last spoken phrase again once, slower. The command is in Settings > Commands > Reading. To set how much slower, go to Settings > Speech > Repeat slower by.
* Vibration type: Haptic effects, Pulses or On and off. Go to Settings > Sound and vibration > Vibration type. Only the types that the vibrator can play are listed.
* Sounds: Screen hidden, Screen shown and Full charge. Go to Settings > Sound and vibration > Individual sounds and vibrations.
* Battery level: says the battery level every 5% or 10%, or every 15, 30 or 60 minutes. Go to Settings > Verbosity > Battery level. Battery level voice is on the same screen.
* Low battery: when the screen turns on, SandFly says the battery level when it is below the level you choose. Go to Settings > Verbosity > Screen on and off > When the screen turns on > Low battery.
* Announce call length: when a phone call ends, SandFly says how long it lasted. Go to Settings > Verbosity > Announce call length.
* Include seconds in the time: go to Settings > Verbosity > Include seconds in the time. To leave seconds out of the time said when the screen turns on, turn off Include seconds when the screen turns on.
* Hidden screen: while the screen is hidden, Speak status and the screen on readout can say "Screen hidden". Go to Settings > Verbosity > Status readout, or Settings > Verbosity > Screen on and off.
* Notification list settings: List notifications newest first, without groups, and Leave media players out of the notification list. Go to Settings > Notifications.
* Read over SandFly's speech in a different voice: a notification in a different voice is read at once, over the current speech. Go to Settings > Notifications > Reading notifications > Voice.
* SandFly keyboard: an input method for physical keyboards, with no keys on the screen. Held keys type the Alt character or the capital letter, keys pressed twice can type other characters, and Double space types a period. Search emoji, Choose a symbol and an editing mode for the cursor and selection are commands in Settings > Commands > Text editing. To turn it on, go to Settings > Typing > Physical keyboard > SandFly keyboard.
* Keyboard phone keymap and Keyboard phone single-key keymap: keymaps for phones with a built-in keyboard and no Ctrl, Meta or arrow keys, such as Unihertz Titan, BlackBerry KEY2 and Zinwa Q25 phones. SandFly uses the Keyboard phone keymap on these phones. Go to Settings > Keyboard shortcuts > Choose a keymap.
* Letter keys press keypad buttons and Enter sends messages: on keyboards whose letters carry numbers, letter keys press the buttons of the PIN pad, the call keypad and calculators. With Enter sends messages on, Enter presses the Send button in messaging apps. Go to Settings > Typing > Physical keyboard.
* Keyboard shortcuts: a shortcut can work only while a text field is being edited, with Only while editing in the shortcut dialog. Shortcuts can use Sym and Fn, and modifier keys held down, such as Alt + Shift held.
* Hold keys down after the touch and hold delay: at the end of the delay, SandFly presses the key down and passes the rest of the touch to the keyboard, such as for a Delete key that repeats. Go to Settings > Typing > Hold keys down after the touch and hold delay.
* Gboard key vibration: with Shizuku or root, Gboard and Pixelboard versions before 18.8 play the key feedback set in their own settings, such as Vibrate on keypress.
* Dictation settings: Speak dictated text, Automatic punctuation and Block offensive words. Go to Settings > Typing > Dictation.
* Braille commands: type braille cells on the screen to run commands, search for an app, or find text on the screen. Use the Braille commands command, or hold dots 4, 5 and 6 on the braille keyboard and swipe left. To change the cells, go to Settings > Braille > Braille commands. Cells can differ by app and by braille command profile. Find text, Find next text and Find previous text are in Settings > Commands > Braille. Braille commands need Android 11 or later.
* Custom braille characters: characters or texts typed with braille cells that you choose, for a braille table. Go to Settings > Braille > Braille keyboard > Custom braille characters.
* Update dot positions while typing: each typed cell moves the dots of the braille keyboard toward where your fingers land. Go to Settings > Braille > Braille keyboard > Update dot positions while typing. It is on by default.
* Braille tables: Persian, Persian 8-dot Computer Braille, and Romanian, for the braille keyboard and braille displays.
* Volume key settings: SandFly handles every volume key press, with Volume up press and Volume down press commands for a single press, and Hide volume panel. Go to Settings > Volume keys.
* Volume key shortcuts with the screen off: volume key presses with commands run them while the display is off. Go to Settings > Volume keys > Volume key shortcuts with the screen off. It needs Shizuku.
* Change speech volume silently while speaking: while SandFly speaks, volume keys change the speech volume without the announcement. Go to Settings > Volume keys.
* Use root instead of Shizuku: on a rooted device, the features that need Shizuku use root. Go to Settings > Shizuku and root > Use root instead of Shizuku.
* User guide: the SandFly User Guide, in English, Dutch and Indonesian. Go to Settings > Help & feedback > User guide. Version history, on the same screen, opens the SandFly releases page.
* Keyboards trigger for settings profiles: a profile applies while a keyboard you choose is shown. On the screen of a profile, choose Keyboards > Add keyboard.
* Display size: a control for the SandFly quick settings panel. Go to Settings > Quick settings > Quick settings panel > Add control.
* Direct touch for apps: an app can declare that it needs direct touch, or take direct touch only on parts of its screen, such as a game board. Turn such an app on or off in Settings > Touch > Direct touch. The interface for developers is in the user guide, Appendix G.
* New commands: Move to item on the left and Move to item on the right (Navigation); Activate confirm button, Activate cancel button and Double tap taps the screen in this app (Activation); Read from focused item by reading control and Speak coordinates (Reading); Switch language automatically and Identify languages from words (Speech); First reading control, Next reading control list and Previous reading control list (Reading controls); Character count and Read text field (Text editing); Share image of focused item and Share screenshot (Image and screen descriptions); Show the focus indicator and Gestures for this app (SandFly); Copy item details (Developer settings).

## Changes

* Speech > Equalizer is now Speech > Voice effects. The equalizer has 11 bands, without the 32 Hz band. Presets saved before keep their other bands.
* Inspect focused item opens Item details, a window with Texts, Item types, Items inside, Script details and App. Activate a line to copy its value, or choose Copy all. Copy screen tree copies text instead of JSON.
* Add label and Edit label are offered for controls that have text, and a custom label replaces the text and description of the item. Add or edit labels runs at once from a gesture or key.
* Recognize swipes before lifting off: a one-finger swipe still runs before the finger lifts when no gesture that starts in its direction has a command.
* A multi-finger tap runs at once when no gesture with more taps, or tap and hold, with as many fingers has a command.
* Time between one-finger taps goes up to 2 seconds.
* An edge menu holds up to 20 commands, up from 10.
* Gestures with no command are labelled Unassigned instead of Tap to assign.
* Activate with a tap taps the middle of the visible part of the focused item, and needs Android 11 or later instead of Android 13.
* Swipes from the app, the status bar or the navigation bar no longer move into the on-screen keyboard. With any typing method except double-tap, a swipe from the keyboard goes on from the text field.
* A picture-in-picture window is one item for swipes. Its controls are in the actions of the item.
* After Back, focus returns to the list item that you activated.
* Scroll left and Scroll right swipe across pagers that have no scroll actions, such as the folder tabs in Solid Explorer.
* Page numbers of a focused pager follow Speak list information. After a pager scrolls, page numbers follow Always speak number of list items.
* Telegram: the Share button beside each message in a channel is not focused by swipes or touch. It is in the actions of the message.
* Reading control lists have their own order: under Current, choose a reading control to move it up or down or remove it.
* Copy text from screen lists the text on the screen. Scroll up and Scroll down add the text of the next page, and the list scrolls back when the window closes. The window opens full screen.
* Clipboard history: opened from a text field, double-tap a text to paste it. Select checks texts to remove or export them. The texts of the clipboard history and the dictionaries have their options in the Actions menu.
* Granular editing has Find previous, and opens on items whose text is only a description.
* Write an app's name to open it: swipe down with two fingers for the previous app, and double-tap to open the app.
* With Capital letters set to anything other than Say "capital", a capital letter on its own is sent to the speech engine in lower case.
* Symbol dictionary entries name characters where SandFly names a single character, such as when you delete it. Entries for punctuation that speech engines do not read aloud are left out while the punctuation level leaves that punctuation out.
* SandFly says the misspelled-words hint, and checks spelling at the cursor, only while Proofread is in the reading control list in use.
* With Identify languages from words on, new text is spoken in its language the first time.
* A settings profile that sets the speech engine changes it without an announcement.
* Let other apps speak lists the apps that used the speech service, each with a switch.
* Sound theme sources lists the SandFly themes.
* Verbosity > Screen on and off: When the screen turns off and When the phone is unlocked have the same items as When the screen turns on. Battery is a list with Off, Always and Only while charging.
* On a flip phone, waking the cover screen speaks the screen on readout.
* The status readout says the mobile network of each active SIM.
* A notification in the voice profile that SandFly speaks with is read after the current speech. A notification in a different voice also waits for the current speech, up to 45 seconds.
* Hide screen covers the navigation bar. While SandFly is paused, the screen is shown, and it is hidden again when SandFly resumes.
* Auto stop after silence has 1 and 2 seconds.
* Braille keyboard: in number, phone and date fields, such as the amount fields in Revolut, words start in numbers. SandFly speaks what you type into fields that report no text.
* While the braille keyboard or the handwriting keyboard is shown, gestures run only commands that open no window.
* The NVDA keymap has Insert + X, Insert + Ctrl + X and Insert + Ctrl + V: repeat and copy the last spoken phrase, and open the text-to-speech settings.
* Gboard 18.8 and later receive touches through Android touch exploration, as other keyboards do, and play the key feedback set in Gboard settings.
* Back up and restore > Export settings saves a .zip file that also holds custom labels, settings profiles, installed scripts, sound themes and the wallpaper image.
* Update downloads resume after a dropped connection, and the progress shows the time left.
* Problem reports include the last volume key events and the enabled accessibility services.

## Fixes

* Swipes through long lists and articles could stall, skip rows, step back, or move focus to an unrelated item after the list scrolled.
* Swipes past the last row on screen in Android Settings waited for the scroll animation, and swipes made during a scroll were lost.
* Swipes could scroll a list or scroll view when the focused item was its last item and fully shown.
* Apps that load more items at the end of a list did not load them when you swiped past the last item.
* The notification shade did not scroll when you swiped past its last shown row.
* Horizontal lists of narrow items did not scroll when you swiped past the last item on screen.
* In Android file picker, swipes through the file list said nothing or skipped files.
* After a two-finger scroll on a web page, focus could move to the wrong item, and input was delayed.
* A list row partly covered by the navigation bar, or with its text off screen, was spoken as its position only, such as "11 of 26".
* Flutter page views turned the page instead of moving to the previous item.
* Explore by touch read nothing in apps that report only an empty container that covers the window.
* Clickable icons whose only content is a decorative image could be skipped or spoken without a name, and items named only by the focus event of the app were spoken as "Unlabelled".
* The Characters and Words reading controls did not move through items that a script reads as one item.
* After a SandFly menu or dialog closed, the gestures, keyboard shortcuts and speech dictionary entries of the app, and settings profiles for the app, did not apply until another window opened.
* Gestures and keyboard shortcuts set for System UI did not run while the notification shade, Quick Settings or the lock screen was the active window.
* Scripts limited to an activity stopped working after a dialog or menu of the app opened and closed.
* With Handle two-finger swipes in SandFly on, a two-finger swipe up on the lock screen did not unlock the phone or show the PIN, pattern or password.
* A two-finger swipe up on the home screen did not open the apps list when more than one home app was installed.
* Two-finger scrubs that went up and down, or started with a slide in from an edge, were not recognized while Handle two-finger swipes in SandFly was on.
* A multi-finger touch in which a finger moved could count as a tap.
* After the screen turned off during a touch, gestures could stop working until SandFly restarted, and volume keys changed the speech volume instead of the media volume.
* On flip phones, such as the Galaxy Z Flip, gestures on the cover screen did nothing when SandFly started with the phone open.
* With Low-latency audio, speech could stop mid-utterance on Samsung phones.
* Speech became quieter when another app requested audio focus that may lower other audio.
* On some Samsung phones, the screen turned off during continuous reading.
* With a voice profile in use, text in another language stayed in the voice of the profile instead of switching to the voice set in Voices by language.
* Voices by language treated three-letter language codes, such as eng from eSpeak and RHVoice, as separate languages.
* Latin letters were not spoken phonetically in languages with a country, such as ru-RU.
* Speak "emoji" after emoji names had no effect, and could not be changed, while the speech engine read emoji.
* Speech dictionary entries did not apply in Granular editing and in some SandFly windows.
* Find in Granular editing started again from the top when no piece had focus.
* Clear selection did not collapse the selection in text fields.
* In message fields with a description, such as in Signal and Messenger, moves by word and character were read as selection changes.
* The cursor moved when navigation was locked to an editable field that is not a standard text field.
* The Paste gesture did not paste when the edit box had no input focus.
* A notification summary read in a voice profile did not stop with a gesture or with the Stop reading settings.
* The notification list showed only the title of notifications with a custom layout, such as Samsung Weather.
* On Vivo phones, SandFly said the name of the Notification Center pane when a heads-up notification arrived.
* Turning on a setting in Summary and time, other than Read notifications every day, opened the Alarms and reminders setting.
* Charger connected was said in the battery state after the charger was unplugged.
* Volume change feedback played when a call started ringing, and moved the ringtone off the speaker.
* Volume key presses could stop working when the screen turned on late or SandFly was suspended.
* The braille keyboard crashed SandFly when a braille keyboard gesture was changed.
* Italian 6-dot Computer Braille typed digits instead of the letters A to J, and no digits after the number sign.
* The braille keyboard read a phone laid flat in portrait as landscape, and said that the charging port was on the right.
* The next braille cells replaced a word typed without a space after the cursor moved out of it.
* A braille display connected while the braille keyboard was shown left the whole screen passed through to the keyboard.
* A braille display moved back from the focused item after a timed message.
* Vibration strength did not apply to braille keyboard vibrations.
* With the screen hidden, the screen could turn off during a video on older Android versions.
* Text recognition on the lock screen after the phone started could crash SandFly.
* Changing Do Not Disturb on a notification settings screen could crash SandFly.
* SandFly could crash when it stopped while speech was queued.
* SandFly turned off when Google Play services was updated.
* On Xiaomi phones with HyperOS, network requests, such as AI descriptions and online translation, failed while another app was in front.
* The screen brightness percentage was wrong on phones with a wide brightness range.
* After Describe screen or Describe image, a question asked by voice ended at once with "No speech recognized".
* Cancelling a dictation model download left the partial file.
* Opening the command list could make SandFly stop responding.
* A shortcut dialog closed after "Key already in use" kept every key press, so no keyboard shortcut worked until SandFly restarted.
* Commands had an unnamed command that opened the keyboard shortcuts settings. It is now Open keyboard shortcuts settings, in Settings > Commands > SandFly.
* Checking a box in SandFly settings could move accessibility focus. Buttons of settings dialogs could be hidden under the keyboard with long text.
* Settings in this profile showed no title for some settings, such as voice profile, equalizer and language voice settings.
* Back from the settings opened with the app icon went to the main settings screen again instead of leaving settings.
* After an update was installed, SandFly said that the update was canceled.
* The update check said it could not check for updates while a new build was being published.
* Watches: sending a problem report could close SandFly, and the time announcement when the watch wakes could be cut off.
