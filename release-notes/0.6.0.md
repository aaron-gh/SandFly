## New

* AI agent follow-ups (SandFly Pro): Start or stop AI agent task now records the task by voice and starts the task when you stop speaking. When the agent asks a question, SandFly speaks it and records your answer. After the agent replies, the conversation stays open for 10 minutes: use the command again to give a follow-up task. To type a task instead, use Type AI agent task in Settings > Commands > Image and screen descriptions, or choose it in the AI actions reading control.
* Usage limit (SandFly Pro): Settings > SandFly Pro shows how much of the monthly usage limit is used. After an agent task, SandFly says the percentage once a month when 80 percent or more is used. SandFly Pro is available at three levels: SandFly Pro, SandFly Pro (2x) and SandFly Pro (4x), with 2 or 4 times the monthly usage limit. To buy SandFly Pro or enter a code, go to Settings > SandFly Pro.
* Scroll ahead to the next item: when the last item of a list on screen is focused, SandFly scrolls the list forward while it speaks the item, so that the next swipe moves at once. After a move to the previous item, SandFly scrolls back. Go to Settings > Navigation > Scroll ahead to the next item. It is on by default.
* Speak the next item while scrolling: when a swipe or key has to scroll a list, SandFly speaks the next item as soon as it appears, while the list is still moving. Go to Settings > Navigation > Speak the next item while scrolling. It is on by default.
* Macros: a macro runs a series of steps as one command. Go to Settings > Macros, and choose Add macro. Steps can run a command, wait, tap, focus or speak an item, speak a text, open an app or type text. Conditions include If, Else if, Else, Repeat, Repeat while, Wait until and Stop macro, with tests of the items on screen, the focused item, the app in front, the keyboard and the lock screen. Item text can be matched as a regular expression. Each macro is a command in Settings > Commands > Macros.
* Voice commands: you can chain voice commands with "then" or "and", run any command by its name, call a contact or number, send a message by SMS or WhatsApp, describe the screen and send the description, open an app, tap an item, type text and wait. SandFly reads a message back and sends it after you say yes. To add your own phrases, go to Settings > Voice commands > Custom voice commands. To send commands that SandFly does not understand to the AI service, turn on Understand voice commands with AI on the same screen.
* Settings profiles: a profile holds the settings you change in it, and applies them in the apps you choose, in web content, during continuous reading or while editing text. Go to Settings > Settings profiles, and choose New settings profile. To change the settings of a profile, choose Change settings on its screen. The commands Choose settings profile, Next settings profile and Previous settings profile are in Settings > Commands > SandFly.
* SandFly menu and custom menus: the SandFly menu is now made of commands. Go to Settings > SandFly menu, and choose Add command or Add submenu. To make other menus, go to Settings > Custom menus, and choose Add menu. Each custom menu is a command in Settings > Commands > Custom menus. Reading controls with no other command have next and previous value commands in Settings > Commands > Setting values.
* Custom reading controls: a reading control made of commands. Swipe up or down to choose a command, and double-tap to run it. Go to Settings > Reading controls > Custom reading controls, and choose Add reading control.
* Clipboard history reading control: in an edit box, swipe up or down to go through the clipboard history, and double-tap to paste the text that SandFly spoke. To add the reading control, go to Settings > Reading controls > Actions for current item > Clipboard history.
* Edit and export the clipboard history: in Clipboard history, choose Edit in the actions of a text to change the text. To save the whole history as a text file, choose Export to file.
* Speech history: lists the last 100 texts that SandFly spoke, to read or copy them. The texts are kept only in memory, and speech while a password field has focus is left out. The command is in Settings > Commands > Reading.
* Copy text from screen: lists the text on the screen by characters, words, paragraphs, or addresses and numbers, to check and copy. Select last spoken phrase word by word lists the words of the last spoken phrase. The commands are in Settings > Commands > Text editing.
* Export to file and Import from file: macros, gesture profiles, gestures in apps, keymaps, settings profiles, dictionaries and custom voice commands can be saved to a file and read from a file. The actions are on the screen of each list and each item. To write a file by hand or with an AI chat, use Settings > Back up and restore > Export file format reference.
* Corner gestures: tap, double-tap, triple-tap, double-tap and hold, or triple-tap and hold a corner of the screen to run a command. Go to Settings > Gestures > Corners. Corner size and Corner tap time limit are on the same screen. Corner gestures need Android 13 or later.
* Recognize swipes before lifting: a one-finger swipe runs after the finger moves 1 cm, before it lifts. While it is on, back-and-forth and angle gestures are turned off. Go to Settings > Gestures > Recognize swipes before lifting. Each gesture profile has its own setting.
* Gesture start time: sets how long a one-finger swipe may take to move 1 cm before it becomes explore by touch. Go to Settings > Gestures > Gesture start time.
* Speak command at each click: when you slide in from an edge, SandFly says the command that lifting at each click runs. Go to Settings > Gestures > Edges > Speak command at each click.
* Double-tap moves cursor to start or end: double-tap the text field you are typing in to move the cursor to the start, or to the end when it is already at the start. Go to Settings > Typing > Double-tap moves cursor to start or end.
* Voices by language: SandFly detects the language of text from its writing, and speaks each language with the voice you choose. Go to Settings > Speech > Voices by language, and choose Add language. To tell apart languages that use the same letters, turn on Settings > Speech > Identify languages from words.
* Emoji voice and Emoji speech rate: emoji can use another voice profile and speech rate. Go to Settings > Speech > Emoji voice, and Settings > Speech > Emoji speech rate.
* Read line breaks as spaces: SandFly speaks each run of line breaks as one space, so that speech does not pause at them. Go to Settings > Speech > Read line breaks as spaces.
* Speak "emoji" after emoji names: go to Settings > Verbosity > Text and symbols > Speak "emoji" after emoji names.
* Equalizer presets: to save the equalizer bands under a name, go to Settings > Speech > Equalizer, and choose Save as preset. Saved presets are available to SandFly default and every voice profile.
* Volume reading controls: Media volume, Call volume, Ring volume, Notification volume and Alarm volume. Swipe up or down to change the volume. To add them, go to Settings > Reading controls > Sound and vibration.
* Audio output device reading control: swipe up or down to choose where SandFly speech plays. To add it, go to Settings > Reading controls > Speech > Audio output device.
* Volume key settings: Silence tone during media playback, Silence speech during media playback, and Interrupt speech to announce the volume are in Settings > Volume keys. On Samsung phones, Volume keys change speech volume while speaking is on the same screen.
* New commands: Move to item below and Move to item above (Navigation); Switch keyboard (Text editing); Older app, Newer app and Answer call (System actions); Time announcements on or off (Notifications); Turn direct touch on or off for this app (Activation); a command for each Live recognition mode (Live recognition); Set reading control to a named reading control (Reading controls). Script commands are listed in Settings > Commands > Scripts.
* Number of notifications: when the screen turns on, SandFly says the number of notifications after the time. Go to Settings > Verbosity > Screen on and off > When the screen turns on > Number of notifications. It is on by default.
* Capitalize sentences: the braille keyboard capitalizes the first letter of a sentence. Go to Settings > Braille > Braille keyboard > Capitalize sentences.
* AI services: Qwen, Zhipu GLM, Baichuan, DeepSeek, Kimi, Hunyuan and SiliconFlow. Go to Settings > AI services > AI service.
* Model download server: Whisper and on-device AI models can download from hf-mirror.com. Go to Settings > AI services > Model download server, or Settings > Typing > Dictation > Model download server.
* Sounds: SandFly plays a sound while the on-device AI model loads, and a sound when SandFly posts a notification without a sound. Go to Settings > Sound and vibration > Individual sounds and vibrations.
* Scripts: script commands can load the script only when they run, scripts can keep running with the screen off, and script actions can come before the actions of the app.

## Changes

* Selecting a reading control says its current value after its name, such as "Speech rate, 60 percent".
* Speech starts sooner after a swipe: SandFly speaks the next item before the app moves focus to it.
* Swipes past long list items and lists that scroll move to the next item sooner.
* The scroll sound plays only for scrolls that you make or ask for, not for scrolls that move to the next or previous item.
* Moving by list item goes from item to item of the list, passing over the buttons inside items.
* With Wrap around off, moving past the first or last item says the item again with the end sound, and reading controls stop at their first and last value.
* With Always speak number of list items off, SandFly speaks no list position when a list scrolls.
* The Scroll reading control swipes the list when the list does not scroll with the scroll action.
* Swipe and hold gestures run when the hold time ends, before the finger lifts.
* In a text field, Left and Right toggle only after you hold them together for 400 ms.
* Speak grid and table information also covers staggered grids and grid pagers.
* The Reading controls screen has more groups. Automatic translation is under Speech, Wrap around and Scroll are under Basic navigation, and Hide screen is under Display.
* AI service, On-device AI and Keep recognition models loaded are in Settings > AI services.
* Speak letters phonetically is now two settings: Speak letters phonetically when reviewing, and Speak letters phonetically when typing.
* Keep recognition models loaded has Until SandFly stops.
* Text in images and on the screen is recognized in Chinese, Japanese, Korean and Devanagari, by the speech and system languages.
* Symbol dictionary entries apply to a character spoken on its own.
* The equalizer also applies to speech that the speech engine plays itself.
* The volume announcement interrupts current speech. To make it wait, turn off Settings > Volume keys > Interrupt speech to announce the volume.
* A Bluetooth device chosen as Audio output is no longer put in call mode.
* Hide screen sets the screen brightness to the minimum while the screen is hidden.
* Clipboard history opens over the screen it is opened from, and Paste types into the edit box directly. Add to clipboard is in the actions of a text.
* The Editing menu has Clear text.
* Voice commands and questions end at the first pause, and voice commands are not changed by AI.
* When the system overview opens in place of SandFly overview, SandFly says whether Shizuku is not running or does not allow SandFly. The grid of the overview has larger cells.
* Notification rules: conditions that look for text have Edit.
* Text fields in SandFly settings are single-line where one line is expected, Enter presses OK, and autofill is off.
* Install SandFly script opens .lua files shared from messaging apps and file managers.
* Controls whose sound does not play still vibrate.
* EuroBraille displays: right joystick left and right, Backspace, and Backspace with dots can be assigned separately.
* Space with dots 1 4 7 8 on a braille display runs no command until assigned.
* Braille display settings list paired displays that a Bluetooth scan does not find.
* The braille keyboard opens sooner.
* Turkish uncontracted braille: dots 3 4 type a slash, and dot 4 types an at sign.
* In Simplified Chinese, Latin letters are spoken with their position in the alphabet.
* Summary and time shows Turn on Alarms and reminders when the time is said at intervals without that permission.
* Automatic icon descriptions is removed from Image and screen descriptions.
* Problem reports include the last gestures, and a failed AI model list names the error.
* New text, including voice command phrases, is translated into every language of SandFly. Dutch translation completed, and Ukrainian, Russian and Belarusian wording corrected.

## Fixes

* Large web pages, such as nested menus, could stop SandFly responding for several seconds after they opened or during fast swipes.
* Speak punctuation and symbols had no effect with speech engines that ignore punctuation markup, such as IBM Eloquence and RHVoice.
* A loading bar in Chrome could silence all speech and sounds with Low-latency audio until SandFly restarted.
* Bridge engines, such as Dual Bridge TTS, repeated speech longer than about 4 seconds.
* On web pages, items on a newly opened page could be skipped, and focus could leave the web view when moving back.
* Next item at the last item on the screen did not scroll some scrollable containers.
* A braille display moved back while you read an element when the same element was shown again.
* Speech dictionary entries did not apply in SandFly notification list.
* Two-finger scrubs were sometimes not recognized.
* Accessibility shortcut commands on Samsung phones showed a chooser or did not start the feature.
* The time announcement said the battery level without "percent" with some speech engines.
* Grid pagers, such as home screen folders, reported the wrong row and column.
* Accessibility focus left the edit box when a navigation bar button took input focus.
* The first text typed into an empty field was read twice.
* Submit text did nothing in the full-screen editor of a keyboard.
* The first circle menu item touched was cut off.
* Granular editing hid spaces and blank lines, and deleted more than the chosen pieces.
* Opening a recent app from SandFly overview could fail.
* Swiping up on the Punctuation reading control chose the next value.
* With Change reading control automatically off, the Actions reading control changed on items without actions.
* Braille display commands that switch the typing or reading language typed dots while editing text.
* Chinese phonetic letters used the wrong table in some regions.
* Turkish uncontracted braille back-translated ığ, şığ, ae, ij and oe wrongly.
* In Dutch, hints for app actions had wrong grammar.
* Watches: edge gestures were active although their settings are hidden, and sending a problem report could fail.
