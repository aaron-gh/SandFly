## Słownik poleceń głosowych {#appendix-voice-commands}

Poniżej są frazy dla polskiej wersji SandFly. Słowa pisane wielkimi literami zastąp nazwą, liczbą lub tekstem. Na przykład „otwórz APLIKACJĘ” powiesz jako „otwórz Chrome”. Wielkość liter i interpunkcja dodana przez rozpoznawanie mowy nie mają znaczenia.

Możesz również powiedzieć nazwę z ekranu **Polecenia** albo nazwę własnego makra, menu lub działania skryptu. Własne [frazy głosowe](#voice-commands-custom) są sprawdzane najpierw. W rozdziale [Polecenia głosowe](#voice-commands) znajdziesz [uruchamianie poleceń](#voice-commands-start) i [kolejność rozpoznawania](#voice-commands-phrases).

### Nawigacja {#appendix-voice-commands-navigation}

| Powiedz | Co zrobi SandFly |
| --- | --- |
| „Następny nagłówek”, „następna kontrolka”, „następny link” lub „następny punkt orientacyjny” | Przejdzie do kolejnego elementu wybranego rodzaju. Możesz też użyć nazwy polecenia z listy. |
| Polecenie z „pierwszy” lub „do góry” | Przejdzie na pierwszy element ekranu. |
| Polecenie z „ostatni” lub „na dół” | Przejdzie na ostatni element ekranu. |
| „Znajdź TEKST”, „szukaj TEKST” lub „wyszukaj TEKST” | Przejdzie do pierwszego elementu z tym tekstem. |
| „Znajdź” | Przejdzie do kolejnego wyniku ostatniego wyszukiwania. |
| „Szukaj na ekranie” lub „wyszukiwanie zawartości ekranu” | Otworzy wyszukiwanie na ekranie. |
| „Czynności”, „czynności niestandardowe” lub „czynność” | Otworzy menu czynności elementu, na którym jest fokus. |

### Sterowanie czytaniem {#appendix-voice-commands-reading-controls}

Powiedz „nawigacja typu” i nazwę opcji, na przykład „nawigacja typu słowa”. W zależności od opcji SandFly może rozpoznać też „nawigacja po elemencie”, „szczegółowość” lub „czytanie typu” z jej nazwą. Możesz wybierać znaki, słowa, wiersze, akapity, nagłówki, elementy sterujące, punkty orientacyjne, okna i nawigację domyślną. Zobacz [sterowanie czytaniem](#reading-controls).

### Czytanie {#appendix-voice-commands-reading}

| Powiedz | Co zrobi SandFly |
| --- | --- |
| „Czytaj od góry” | Rozpocznie czytanie od początku ekranu. |
| „Czytaj od zaznaczonego elementu” lub „czytaj od kursora” | Rozpocznie czytanie od bieżącej pozycji. |
| Nazwę polecenia kopiowania ostatniej wypowiedzi z listy **Polecenia** | Skopiuje ostatnią wypowiedź. |

### Edycja tekstu {#appendix-voice-commands-text-editing}

Najpierw przejdź do pola, w którym chcesz pisać.

| Powiedz | Co zrobi SandFly |
| --- | --- |
| „Wpisz TEKST”, „napisz TEKST” lub „wprowadź TEKST” | Wpisze podany tekst. |
| „Zaznacz wszystko” | Zaznaczy treść pola. |
| „Zaznacz”, „zacznij zaznaczać”, „zacznij zaznaczanie” lub „uruchom tryb zaznaczania” | Włączy tryb zaznaczania. |
| „Zakończ zaznaczanie”, „zakończ wybieranie”, „zamknij tryb zaznaczania” lub „skończ zaznaczać” | Wyjdzie z trybu zaznaczania. |
| „Kopiuj”, „wytnij”, „wklej” lub „usuń” | Skopiuje lub wytnie zaznaczenie, wklei schowek albo usunie zaznaczenie. |

### Połączenia i wiadomości {#appendix-voice-commands-calls}

Podaj kontakt albo numer. W nazwie kontaktu użyj formy, pod którą jest zapisany. Bez wybranej aplikacji SandFly używa domyślnej aplikacji SMS. Przy SMS lub WhatsApp przed wysłaniem prosi o potwierdzenie. W innych komunikatorach wybierasz rozmowę po otwarciu udostępniania.

| Powiedz | Co zrobi SandFly |
| --- | --- |
| „Zadzwoń do KONTAKTU”, „zadzwoń na NUMER” lub „połącz z KONTAKTEM” | Rozpocznie połączenie. |
| „Napisz do KONTAKTU TEKST” albo „wyślij SMS do KONTAKTU o treści TEKST” | Przygotuje wiadomość. |
| „Wyślij wiadomość do KONTAKTU przez APLIKACJĘ o treści TEKST” lub „napisz do KONTAKTU w APLIKACJI TEKST” | Przygotuje wiadomość w podanej aplikacji. |
| „Wyślij wiadomość APLIKACJA do KONTAKTU” | Poprosi o treść i przygotuje wiadomość. |

Na pytanie o wysłanie powiedz „tak”, „wyślij”, „jasne” lub „okej”. Jeśli nie potwierdzisz, wiadomość zostanie w aplikacji.

### Opisy {#appendix-voice-commands-descriptions}

| Powiedz | Co zrobi SandFly |
| --- | --- |
| „Opisz ekran” lub „co jest na moim ekranie” | Opisze ekran. |
| „Opisz ten obraz”, „opisz to zdjęcie” lub „co jest na tym obrazie” | Opisze obraz, na którym jest fokus. |
| „Skopiuj to”, „skopiuj opis” lub „skopiuj ostatnią wypowiedź” | Skopiuje ostatni opis, a jeśli go nie ma, ostatnią wypowiedź. |
| „Wyślij opis do KONTAKTU” lub „wyślij to do KONTAKTU przez APLIKACJĘ” | Użyje opisu lub ostatniej wypowiedzi jako wiadomości. |
| „Wyślij opis tego obrazu do KONTAKTU” | Utworzy opis obrazu i przygotuje wiadomość. |
| „Wyślij opis ekranu do KONTAKTU” | Utworzy opis ekranu i przygotuje wiadomość. |

### Łączenie poleceń {#appendix-voice-commands-chains}

„Potem”, „a potem”, „następnie”, „a następnie” i „po tym” mogą łączyć kroki, na przykład „otwórz Ustawienia, a potem kliknij Dostępność”. „I” działa również wtedy, gdy po obu stronach jest odrębne polecenie.

Przed poleceniem możesz powiedzieć „proszę”, „czy możesz”, „możesz”, „chcę”, „chciałbym”, „chciałabym” lub „teraz”. Po nim możesz dodać „proszę”, „dla mnie” lub „teraz”. SandFly pomija te zwroty przy rozpoznawaniu.
