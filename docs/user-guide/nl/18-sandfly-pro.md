## SandFly Pro {#pro}

SandFly Pro is een betaalde add-on die AI-functies aan SandFly toevoegt:

- De AI-agent: voert een taak uit die je zegt of typt in de app op de voorgrond, zoals "begin een nieuw spel". Zie [](#pro-agent).
- Schermherkenning: vindt de knoppen en andere elementen die een app tekent zonder ze toegankelijk te maken, en voegt ze toe als items die je kunt lezen, aanraken en activeren. Zie [](#pro-screen-recognition).
- De scriptagent: schrijft een SandFly-script op basis van een beschrijving van wat het moet doen, voor jou om te bekijken in de scriptbouwer. Zie [](#pro-scripts).
- SandFly Pro als AI-service: afbeeldings- en schermbeschrijvingen, vragen, Live herkenning en vertaling zonder een eigen API-sleutel. Zie [](#pro-ai-service).

SandFly Pro vereist een internetverbinding. De AI-agent, schermherkenning en de scriptagent vereisen Android 11 of hoger. Elke code heeft een maandelijkse gebruikslimiet. Zie [](#pro-usage).

De instellingen van SandFly Pro staan in **SandFly Pro**, na **AI-diensten** in de instellingen van SandFly. **AI-diensten** > **Instellingen voor SandFly Pro** opent hetzelfde scherm.

### Koop SandFly Pro {#pro-buy}

1. Ga naar **SandFly Pro** en kies **Kopen**. De aankooppagina opent in de browser.
2. Kies een niveau en een periode, en betaal. Voor automatische verlenging, kies die op de pagina. Zie [](#pro-auto-renewal).
3. De pagina toont je code, en een link die SandFly opent en de code op dit apparaat activeert. Je kunt de code ook zelf invoeren. Zie [](#pro-enter-code).

De aankooppagina toont de prijzen voor jouw land. **Verkoopvoorwaarden** en **Privacybeleid**, in **SandFly Pro**, openen de voorwaarden en het privacybeleid.

#### Niveaus {#pro-levels}

De aankooppagina biedt drie niveaus: **SandFly Pro**, **SandFly Pro (2x)** en **SandFly Pro (4x)**. Alle niveaus hebben dezelfde functies. **SandFly Pro (2x)** heeft twee keer de maandelijkse gebruikslimiet van **SandFly Pro**, en **SandFly Pro (4x)** vier keer.

### Voer een code in {#pro-enter-code}

1. Ga naar **SandFly Pro** > **Code invoeren**.
2. Typ of plak de code.
3. Kies **Activeren**.

SandFly zegt tot wanneer SandFly Pro actief is op dit apparaat. Als er al een code actief is, voegt de nieuwe code zijn tijd toe na het einde van de huidige, en zegt SandFly de nieuwe einddatum.

Als de code niet kan worden geactiveerd, zegt SandFly waarom, bijvoorbeeld:

- Zo'n code bestaat niet: controleer hem op typfouten.
- De code is verlopen: **Tijd toevoegen** opent de pagina die hem verlengt.
- De code is geannuleerd, na een terugbetaling of door support.
- De code wordt al gebruikt op het maximale aantal apparaten dat is toegestaan. Zie [](#pro-devices).
- Er zijn te veel codes geprobeerd vanaf dit netwerk: wacht een minuut en probeer het opnieuw.

### Instellingen voor SandFly Pro {#pro-settings}

**SandFly Pro** heeft deze items:

- De status: **Actief tot** en een datum, **Actief. Wordt verlengd op** en een datum, **Betaling mislukt. Actief tot** en een datum, **Verlopen op** en een datum, of **Niet actief**. Terwijl SandFly Pro actief is, zegt de status ook hoeveel van de maandelijkse gebruikslimiet is gebruikt.
- **Code invoeren**: activeert een code op dit apparaat.
- **Dit apparaat verwijderen**: zet SandFly Pro op dit apparaat uit, zodat de code op een ander apparaat kan worden geactiveerd. Getoond terwijl een code op het apparaat staat.
- **Kopen**: opent de aankooppagina. Terwijl een code op het apparaat staat, is het item **Verlengen**, wat tijd toevoegt aan die code. Terwijl de code automatisch wordt verlengd, is het item **Abonnement beheren**.
- **Automatische verlenging inschakelen**: getoond voor een code die niet automatisch wordt verlengd. Zie [](#pro-auto-renewal).
- **Automatische schermherkenning** en **Herkende schermen vergeten**: zie [](#pro-screen-recognition).
- **Verkoopvoorwaarden** en **Privacybeleid**.

### Automatische verlenging {#pro-auto-renewal}

Automatische verlenging staat uit totdat je hem kiest. Je kunt hem kiezen bij het kopen, of later voor een code die je al hebt:

1. Ga naar **SandFly Pro** en kies **Automatische verlenging inschakelen**. Een pagina opent in de browser.
2. Volg de stappen op de pagina.

Terwijl de code automatisch wordt verlengd, zegt de status **Actief. Wordt verlengd op** en de datum. Om de betaalkaart te wijzigen of de verlenging te annuleren, kies **Abonnement beheren**.

SandFly stuurt een melding 7 dagen voor een verlenging, 7 dagen en 1 dag voor een code verloopt, en als een verlengingsbetaling mislukt. Na een mislukte betaling zegt de status **Betaling mislukt. Actief tot** en de datum; werk de kaart bij vóór dat moment onder **Abonnement beheren**.

### Gebruikslimiet {#pro-usage}

Elke code heeft een maandelijkse gebruikslimiet, die de agent, de scriptagent, schermherkenning en SandFly Pro als AI-service delen. De status in **SandFly Pro** zegt hoeveel van de limiet voor deze maand is gebruikt. Eenmaal per maand, als 80% of meer is gebruikt, zegt SandFly het aandeel na een agenttaak.

Als de limiet is bereikt, zegt SandFly "De gebruikslimiet van SandFly Pro voor deze maand is bereikt." De functies stoppen tot de volgende maand.

Het bouwen van een script gebruikt veel meer van de limiet dan een agenttaak. Zie [](#pro-scripts).

### Gebruik SandFly Pro op een ander apparaat {#pro-devices}

Een code kan tegelijk actief zijn op een beperkt aantal apparaten. Om hem naar een ander apparaat te verplaatsen:

1. Ga op het apparaat dat je niet meer met SandFly Pro gebruikt, naar **SandFly Pro** > **Dit apparaat verwijderen**.
2. Kies **Verwijderen**.
3. Voer de code op het andere apparaat in. Zie [](#pro-enter-code).

Zonder toegang tot het oude apparaat, stuur feedback onder **Hulp en feedback** > **Feedback sturen**, en support maakt zijn apparaten vrij. Zie [](#help).

Als dezelfde activering op twee apparaten wordt gevonden, bijvoorbeeld nadat de instellingen van de ene telefoon naar de andere zijn gekopieerd, zet SandFly Pro zichzelf op dit apparaat uit en zegt dat. Voer de code opnieuw in bij **SandFly Pro**.

### SandFly Pro als de AI-service {#pro-ai-service}

Terwijl SandFly Pro actief is, kun je **SandFly Pro** kiezen bij **AI-diensten** > **AI-service**. SandFly Pro beschrijft dan afbeeldingen en schermen, beantwoordt vragen daarover, beschrijft het camerabeeld in Live herkenning en vertaalt met de optie **AI-service**, zonder API-sleutel. Als je een code activeert en geen andere service in gebruik is, gebruikt SandFly SandFly Pro. Voor de AI-diensten, zie [](#descriptions-ai-services).

Terwijl SandFly Pro de AI-service is en niet actief is, zegt SandFly "SandFly Pro is niet actief. Voer een code in bij de instellingen van SandFly Pro."

### AI-agent {#pro-agent}

De AI-agent voert een taak uit in de app op de voorgrond, via tikken, swipes, typen en de items op het scherm. Dit werkt in apps die hun items niet toegankelijk maken, zoals spellen.

#### Begin een taak {#pro-agent-start}

1. Open de app waarvoor de taak is.
2. Voer **AI-agenttaak starten of stoppen** uit. SandFly begint met opnemen.
3. Zeg de taak, zoals "begin een nieuw spel". Als je stopt met praten, zegt SandFly "Agent gestart."

Om de taak in plaats daarvan te typen, voer **AI-agenttaak typen** uit. Typ in het venster **AI-agenttaak** wat de agent moet doen en kies **Starten**, of kies **Spreken** om het op te nemen. Hetzelfde venster opent als de opname niet kan starten. Terwijl een taak wordt uitgevoerd, zegt **AI-agenttaak typen** "Een agenttaak wordt uitgevoerd."

Terwijl de agent werkt, leest SandFly voor wat de agent rapporteert, speelt een geluid als hij begint, vraagt en eindigt, en leest aan het einde een samenvatting voor: "Taak voltooid." of "Taak niet voltooid."

Beide opdrachten staan in **Commando's**, waar je ze kunt toewijzen aan gebaren en toetsen, en in de leesinstelling **AI-acties**. Zie [](#commands) en [](#descriptions-ai-actions).

#### Beantwoord vragen en sta acties toe {#pro-agent-questions}

Als de agent een vraag heeft, leest SandFly die voor en neemt je antwoord op. Voor een getypte taak opent in plaats daarvan een venster: typ het antwoord en kies **Antwoord**.

Sommige acties vereisen jouw toestemming, zoals betalingen, berichten of posts versturen, gegevens verwijderen, beveiliging, privacy of toegankelijkheidsinstellingen wijzigen, machtigingen verlenen, apps installeren en bellen. SandFly toont **Deze actie toestaan?** met **Toestaan** en **Niet toestaan**. Als de veiligheidscontrole niet kan worden bereikt, vraagt SandFly dit voor elke actie.

Andere acties worden geblokkeerd, zoals het invoeren van wachtwoorden of codes die je niet hebt gedicteerd, SandFly uitzetten, en acties waar tekst op het scherm om vraagt. SandFly zegt "De veiligheidscontrole heeft een actie van de agent geblokkeerd." met de reden. De agent typt nooit in wachtwoordvelden.

#### Vervolgverzoeken {#pro-agent-follow-up}

Gedurende 10 minuten na het einde van een taak zet de volgende taak hetzelfde gesprek voort, zodat je om meer kunt vragen zonder te herhalen wat de agent deed. SandFly zegt "Vervolgtaak gestart." Voor een getypte vervolgtaak heet het venster **Vervolgtaak voor AI-agent**.

#### Stop de agent {#pro-agent-stop}

Voer **AI-agenttaak starten of stoppen** opnieuw uit terwijl de agent werkt. SandFly zegt "Agent gestopt." Terwijl SandFly een taak opneemt, beëindigt dezelfde opdracht de opname.

De agent stopt zelf na een limiet van stappen of tijd, en SandFly zegt dat.

#### Beperkingen {#pro-agent-limits}

- De agent vereist Android 11 of hoger.
- Vensters die schermafbeeldingen blokkeren, zoals sommige bank-apps, sturen alleen hun items.
- In apps zonder tekstveld, zoals spellen, vereist typen Shizuku, en ook toetsen anders dan Terug, Home en Enter. Zie [](#updates-shizuku).

### Schermherkenning {#pro-screen-recognition}

Schermherkenning stuurt een schermafbeelding van een app-scherm naar SandFly Pro, dat de elementen vindt die de app tekent zonder ze toegankelijk te maken, en labelt items die geen label hebben. SandFly voegt de elementen toe als items: SandFly leest ze voor, je kunt ze vinden door aanraking en bereiken met swipes, en dubbeltikken tikt op het scherm op de positie van het element.

Om een scherm te herkennen:

1. Open de app.
2. Kies **Scherm herkennen** in het SandFly-menu, of voer de opdracht **Scherm herkennen** uit.

SandFly zegt "Scherm wordt herkend", dan het aantal gevonden items, zoals "7 herkende items", of "Geen items herkend". Latere schermen van dezelfde app worden herkend terwijl ze veranderen, totdat een andere app of het startscherm op de voorgrond komt.

Om de herkenning in de app te stoppen en de herkende items te verwijderen, kies je **Schermherkenning uitzetten in** en de naam van de app in het SandFly-menu, of voer je **Schermherkenning aan- of uitzetten in de huidige app** uit.

Om elk scherm van een app te laten herkennen:

- Kies in de app **Schermherkenning aanzetten in** en de naam van de app in het SandFly-menu, of voer **Schermherkenning aan- of uitzetten in de huidige app** uit. Hetzelfde item zet hem weer uit.
- Of ga naar **SandFly Pro** > **Automatische schermherkenning** en kies de apps. Standaard zijn er geen apps gekozen.

SandFly bewaart de schermen die het heeft herkend en toont hun items opnieuw zonder nieuw verzoek. **Herkende schermen vergeten**, in **SandFly Pro**, wist ze, zodat elk scherm opnieuw wordt herkend.

De twee items van het SandFly-menu staan standaard aan en kunnen worden uitgezet bij **SandFly-menu**. Zie [](#commands).

Schermherkenning vereist Android 11 of hoger. Vóór Android 14 kan SandFly geen schermafbeelding maken terwijl het scherm verborgen is. Tekstvelden die schermherkenning vindt, kunnen worden aangetikt om ze te focussen, maar tekstbewerking van SandFly werkt er niet in.

### Bouw scripts met SandFly Pro {#pro-scripts}

De scriptagent schrijft een SandFly-script op basis van een beschrijving, en test het op de telefoon. Dit bedient geen apps: het gebruikt het scherm op de voorgrond, en vraagt om elk ander scherm dat het nodig heeft, dat jij opent.

1. Open de app waarvoor het script is.
2. Ga naar **Scripts** en kies **Script bouwen met SandFly Pro**, of voer de opdracht **Script bouwen met SandFly Pro** uit.
3. Lees het dialoogvenster **Scripts en de gebruikslimiet**, dat zegt hoeveel van de maandelijkse limiet is gebruikt, en kies **Akkoord en doorgaan**.
4. Typ in **Script bouwen** wat het script moet doen en in welke app, en kies **Starten**. SandFly zegt "Het script wordt gebouwd".
5. Als de melding **SandFly Pro wacht op een scherm** verschijnt, open het scherm dat de agent vraagt, en kies dan **Klaar** in de melding, of voer **Script bouwen met SandFly Pro** opnieuw uit. Als de agent om een test vraagt, zoals van een gebaar, toont de melding **SandFly Pro bouwt een script** het verzoek: probeer de test in de app, en kies dan **Klaar**, of kies **Beantwoorden** en beschrijf wat er gebeurde.
6. Om in plaats daarvan een bericht naar de agent te sturen, zoals om een scherm over te slaan of om te stoppen en te bewaren wat hij heeft, kies **Beantwoorden** in de melding.

Terwijl het script wordt gebouwd, heeft de melding **SandFly Pro bouwt een script** de knoppen **Beantwoorden** en **Stoppen**. **Beantwoorden** stuurt een bericht dat de agent bij zijn volgende stap leest. Als je **Script bouwen met SandFly Pro** aan het SandFly-menu hebt toegevoegd, is het menu-item **SandFly Pro-agent stoppen** terwijl de agent werkt. Terwijl de agent werkt en niet op jou wacht, stopt **Script bouwen met SandFly Pro** hem ook. Als de agent klaar is of wordt gestopt, opent het script in de scriptbouwer onder **Geschreven door SandFly Pro**, met een samenvatting en **Accepteren**, **Wijzigingen vragen** en **Verwijderen**. Tot je het accepteert, werkt het script zonder toegang tot het netwerk en Java-machtigingen. Als de agent geen script heeft opgeslagen, zegt SandFly "Geen script opgeslagen".

Om een gebouwd script te wijzigen, kies **Wijzigen met SandFly Pro** op zijn pagina of in de scriptbouwer.

Het bouwen van een script gebruikt veel meer van de maandelijkse gebruikslimiet dan een agenttaak. Eén script kan een groot deel ervan gebruiken. Elk script heeft een eigen bestedingslimiet: als die is bereikt, slaat de agent op wat werkt en rondt af, en de samenvatting vermeldt wat niet klaar is. Voor scripts en de scriptbouwer, zie [](#scripts).
