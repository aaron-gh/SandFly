## Pintasan keyboard default {#appendix-keyboard-shortcuts}

Ini adalah pintasan keyboard untuk setiap peta tombol sebelum Anda mengubahnya, ditulis dengan tombol SandFly yang dipilih untuk peta tombol tersebut. Perintah yang tidak tercantum tidak memiliki pintasan hingga Anda menetapkannya. Untuk memilih peta tombol, mengubah tombol SandFly, atau mengubah pintasan, lihat [](#keyboards).
