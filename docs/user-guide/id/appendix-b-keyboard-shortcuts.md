## Pintasan keyboard default {#appendix-keyboard-shortcuts}

Daftar ini berisi pintasan keyboard setiap peta tombol sebelum Anda mengubahnya. Pintasan ditulis dengan tombol SandFly yang dipilih untuk peta tombol itu. Perintah yang tidak tercantum tidak memiliki pintasan sampai Anda menetapkan pintasan untuknya. Untuk memilih peta tombol, mengubah tombol SandFly, atau mengubah pintasan, lihat [](#keyboards).
