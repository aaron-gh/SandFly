## Keyboard fisik {#keyboards}

Anda dapat menggunakan SandFly dengan keyboard Bluetooth atau USB, atau dengan keyboard bawaan dari ponsel berkeyboard. SandFly menjalankan perintah dari pintasan keyboard, berpindah dengan tombol panah dan satu huruf jika peta tombol Anda menggunakannya, serta dapat meneruskan tombol ke aplikasi yang Anda gunakan. Bab ini menjelaskan **Pintasan keyboard** di setelan SandFly dan setelan keyboard fisik di **Mengetik**. Untuk pintasan default setiap perintah, lihat [](#appendix-keyboard-shortcuts).

Untuk mempelajari pintasan keyboard langkah demi langkah, gunakan tutorial keyboard. Lihat [](#getting-started).

### Tombol SandFly {#keyboards-sandfly-key}

Sebagian besar pintasan keyboard menggunakan tombol SandFly bersama tombol lain, seperti Tombol SandFly + Panah Kanan untuk berpindah ke item berikutnya. Tombol SandFly adalah satu tombol, atau dua tombol yang ditahan bersamaan, yang Anda pilih untuk setiap peta tombol. Tombol ini dapat berupa salah satu dari tombol berikut, tergantung peta tombolnya:

- **Meta**: tombol Windows, di sebelah tombol Alt kiri. Di keyboard Apple, ini adalah tombol Command.
- **Alt**
- **Ctrl + Alt**: kedua tombol ditahan bersamaan.
- **Ctrl + Meta**: kedua tombol ditahan bersamaan.
- **Ctrl**
- **Insert**: pada kebanyakan keyboard, berada di grup enam tombol di atas tombol panah.
- **Insert Numpad**: tombol 0 pada papan angka, saat Num Lock nonaktif.
- **Sym**, **Alt Kanan**, **Shift Kanan**, dan **Fn**: tombol pada ponsel berkeyboard. Lihat [](#keyboards-phones).

Insert, Insert Numpad, Sym, Alt Kanan, Shift Kanan, dan Fn adalah tombol yang tidak diperlakukan Android sebagai tombol pengubah. SandFly mengambilnya saat ditahan, dan tombol tersebut tidak diteruskan ke aplikasi.

Jika Meta menjadi tombol SandFly, menekan Meta saja sekali akan membuka daftar semua aplikasi, sebagaimana perilaku Android. Menekan tombol SandFly dua kali dengan cepat akan mengaktifkan atau menonaktifkan mode penjelajahan pada peta tombol yang menggunakannya sebagai pintasan. Lihat [](#keyboards-browse-mode).

Untuk memilih tombol SandFly, lihat [](#keyboards-choose-sandfly-key).

### Peta tombol {#keyboards-keymaps}

Peta tombol adalah kumpulan pintasan keyboard. SandFly memiliki peta tombol berikut:

- **Peta tombol SandFly**: peta tombol default. Tombol SandFly-nya adalah Meta, Insert, atau Insert Numpad, dengan Meta sebagai default.
- **Peta tombol VoiceOver**: perintah keyboard VoiceOver di iPhone, dengan tombol SandFly sebagai tombol VO. Tombol SandFly-nya adalah Ctrl + Alt, Insert, atau Insert Numpad, dengan Ctrl + Alt sebagai default. Meta menggantikan Command. Dalam mode penjelajahan, tombol tunggal bergerak seperti Navigasi Cepat satu tombol di VoiceOver.
- **Peta tombol NVDA**: tata letak laptop dari NVDA yang tidak memerlukan papan angka, dengan tombol SandFly sebagai tombol NVDA. Tombol SandFly-nya adalah Insert, Insert Numpad, atau Meta, dengan Insert sebagai default.
- **Peta tombol JAWS**: kombinasi tombol desktop JAWS, dengan tombol laptopnya untuk klik dan kursor, dengan tombol SandFly sebagai tombol JAWS. Tombol SandFly-nya adalah Insert, Insert Numpad, atau Meta, dengan Insert sebagai default.
- **Peta tombol Orca**: tata letak laptop dari Orca, dengan tombol SandFly sebagai pengubah Orca. Tombol SandFly-nya adalah Insert, Insert Numpad, Meta, atau Alt, dengan Insert sebagai default.
- **Peta tombol ponsel berkeyboard** dan **Peta tombol satu tombol ponsel berkeyboard**: untuk ponsel dengan keyboard bawaan yang tidak memiliki tombol Ctrl, Meta, atau panah. Lihat [](#keyboards-phones).
- Peta tombol yang Anda buat sendiri. Lihat [](#keyboards-custom-keymaps).

Pada peta tombol NVDA, JAWS, dan Orca, tombol panah dan Tab bergerak tanpa tombol SandFly, seperti di komputer. Lihat [](#keyboards-desktop).

Pada ponsel berkeyboard, peta tombol ponsel berkeyboard adalah peta tombol default. SandFly mengalihkan ponsel berkeyboard dari Peta tombol SandFly ke Peta tombol ponsel berkeyboard satu kali, saat pertama kali dijalankan di perangkat tersebut.

#### Memilih peta tombol {#keyboards-choose-keymap}

1. Di setelan SandFly, buka **Pintasan keyboard**.
2. Pilih **Pilih peta tombol**.
3. Pilih sebuah peta tombol.

SandFly mengumumkan peta tombol yang kini aktif. Setiap peta tombol menyimpan pintasannya sendiri, tombol SandFly-nya sendiri, dan setelan navigasi tombol panahnya sendiri, sehingga mengganti peta tombol tidak mengubah peta tombol lain.

#### Memilih tombol SandFly {#keyboards-choose-sandfly-key}

1. Di setelan SandFly, buka **Pintasan keyboard**.
2. Pilih **Pilih tombol SandFly**.
3. Pilih sebuah tombol.

**Pilih tombol SandFly** menetapkan tombol SandFly untuk peta tombol yang sedang digunakan. Daftar ini hanya mencantumkan tombol yang mempertahankan semua pintasan default peta tombol; peta tombol buatan Anda sendiri menawarkan semua tombol SandFly. Setiap pintasan default tetap menggunakan tombolnya, dengan tombol SandFly baru menggantikan yang lama. Pintasan yang Anda ubah disimpan terpisah untuk setiap tombol SandFly dari sebuah peta tombol.

#### Peta tombol kustom {#keyboards-custom-keymaps}

Anda dapat membuat peta tombol sendiri. Peta tombol baru dimulai sebagai salinan dari peta tombol yang sedang digunakan, beserta pintasannya, tombol SandFly-nya, dan cara kerja tombolnya, seperti tombol panah yang bergerak seperti pada Peta tombol NVDA.

Untuk membuat peta tombol:

1. Pilih peta tombol yang akan disalin. Lihat [](#keyboards-choose-keymap).
2. Di **Pintasan keyboard**, pilih **Peta tombol baru**.
3. Masukkan nama, atau biarkan kosong untuk menggunakan nama yang ditampilkan, seperti "Salinan Peta tombol NVDA".
4. Pilih **Oke**.

Peta tombol baru langsung digunakan. Di peta tombol buatan Anda, pintasan dapat menggunakan tombol apa saja, dengan atau tanpa tombol SandFly. Pintasan tanpa tombol SandFly bekerja di mana saja kecuali di kolom teks yang sedang diedit, di mana tombol diteruskan ke kolom teks. Pada peta tombol yang disalin dari Peta tombol SandFly atau VoiceOver, pintasan semacam itu dengan Ctrl atau Alt juga bekerja di kolom teks. Tombol pengubah yang ditekan sendirian selalu diteruskan ke aplikasi.

Saat peta tombol buatan Anda sedang digunakan, **Pintasan keyboard** juga memiliki:

- **Ganti nama peta tombol**: mengubah namanya.
- **Hapus peta tombol**: menghapusnya, setelah Anda konfirmasi. Peta tombol default kemudian digunakan.

#### Mengekspor dan mengimpor peta tombol {#keyboards-keymap-files}

- **Ekspor ke file**: menyimpan peta tombol yang sedang digunakan, beserta pintasan dan tombol SandFly-nya, ke file yang Anda pilih.
- **Impor dari file**: menambahkan peta tombol dari sebuah file.

Fitur ini tidak tersedia di jam tangan. Untuk format filenya, lihat [](#api-item-files).

#### Mereset peta tombol {#keyboards-reset-keymap}

**Reset peta tombol** mengembalikan semua pintasan pada peta tombol yang sedang digunakan ke tombol defaultnya, dan semua tombol panah ke perintah defaultnya. SandFly meminta konfirmasi terlebih dahulu. Reset tidak dapat dibatalkan.

### Layar Pintasan keyboard {#keyboards-settings}

**Pintasan keyboard** di setelan SandFly berisi:

- **Peta tombol**: **Pilih peta tombol**, **Pilih tombol SandFly**, **Reset peta tombol**, **Lihat pintasan keyboard sistem**, **Peta tombol baru**, **Ekspor ke file**, **Impor dari file**, serta untuk peta tombol buatan Anda, **Ganti nama peta tombol** dan **Hapus peta tombol**. **Lihat pintasan keyboard sistem** membuka daftar pintasan keyboard Android dan aplikasi yang sedang digunakan.
- **Pintasan keyboard di aplikasi**: pintasan yang menjalankan perintah lain di satu aplikasi. Lihat [](#keyboards-app-shortcuts).
- **Telusuri**: menemukan perintah atau tombol panah berdasarkan nama atau tombolnya, lalu membuka pintasannya.
- **Navigasi tombol panah**: pada peta tombol yang memilikinya. Lihat [](#keyboards-arrow-keys).
- Perintah-perintah, menurut kategori, masing-masing beserta pintasannya. Setiap kategori dapat dibuka dan ditutup. Perintah yang pintasannya hanya bekerja dalam mode penjelajahan memiliki keterangan "dalam mode penjelajahan" setelah namanya, seperti "Navigasi ke judul berikutnya dalam mode penjelajahan".

Anda hanya dapat mengubah pintasan dan mereset peta tombol saat SandFly aktif.

Anda juga dapat melihat dan mengubah pintasan keyboard suatu perintah di layarnya sendiri pada **Perintah**. Lihat [](#commands).

### Mengubah pintasan keyboard {#keyboards-change-shortcut}

1. Di setelan SandFly, buka **Pintasan keyboard**.
2. Buka kategori perintah, atau pilih **Telusuri** lalu ketik namanya.
3. Pilih perintah tersebut.
4. Tekan tombol baru.
5. Tekan Enter, atau pilih **Simpan**.

Di dalam dialog:

- Backspace menghapus pintasan, sehingga perintah tidak memiliki pintasan. **Hapus** melakukan hal yang sama.
- Ctrl + Backspace menetapkan kembali pintasan default.
- Escape, atau **Batal**, menutup dialog tanpa perubahan.

Jika perintah lain sudah menggunakan tombol tersebut, SandFly menampilkan "Saat ini ditetapkan ke" beserta nama perintah itu. Saat Anda menyimpan, dialog **Tombol sudah digunakan** menanyakan apakah tombol akan diambil dari perintah tersebut; pilih **Oke** untuk menetapkannya ke perintah yang sedang Anda ubah.

Pintasan untuk **Aktifkan atau nonaktifkan mode penjelajahan** juga dapat berupa tombol SandFly yang ditekan dua kali: tekan dua kali dalam setengah detik. Ctrl + Alt dan Ctrl + Meta tidak dapat ditekan dua kali.

#### Pintasan dua tombol berurutan {#keyboards-sequences}

Pada Peta tombol SandFly dan Peta tombol VoiceOver, serta peta tombol yang disalin darinya, pintasan dapat berupa Tombol SandFly + R atau Tombol SandFly + O diikuti tombol ketiga, seperti Tombol SandFly + O, lalu H. Tekan tombol ketiga dalam 3 detik, dengan atau tanpa tombol SandFly. Tombol ketiga tidak boleh berupa Escape, Backspace, Enter, atau tombol pengubah.

Untuk merekam pintasan seperti ini, tekan Tombol SandFly + R atau Tombol SandFly + O, lalu tombol ketiga.

#### Pintasan yang hanya bekerja saat mengedit {#keyboards-while-editing}

Pilih **Hanya saat mengedit** di dialog pintasan untuk pintasan yang hanya bekerja saat kolom teks sedang diedit. Pintasan semacam ini ditekan tanpa tombol SandFly, dan SandFly mengambil tombolnya dari kolom teks. Di luar kolom teks, tombol bekerja seperti tanpa pintasan. Pintasan ini ditampilkan dengan keterangan "saat mengedit" setelah tombolnya, seperti "Alt + Spasi saat mengedit".

#### Penekanan tombol pada peta tombol ponsel berkeyboard {#keyboards-presses}

Pada peta tombol ponsel berkeyboard, pintasan juga dapat berupa:

- Tombol pengubah yang ditekan sendirian, seperti Sym saja atau Shift + Sym. Penekanan seperti ini diteruskan ke aplikasi kecuali ditetapkan sebagai pintasan.
- Tombol, atau tombol pengubah, yang ditekan dua kali dengan cepat, seperti Alt dua kali. Tekanan pertama diteruskan ke aplikasi seperti biasa; tekanan kedua menjalankan pintasan.
- Tombol pengubah yang ditahan sendirian selama setengah detik, seperti Alt + Shift ditahan.
- Tombol lain yang ditahan, seperti K ditahan. Saat Anda mengetik, tombol yang ditahan tetap mengetik seperti biasa.

Untuk merekamnya, tekan tombol dengan cara yang sama di dialog pintasan. Pada peta tombol ini, Enter yang ditekan sekali menyimpan pintasan sesaat kemudian; Enter yang ditekan dua kali merekam Enter dua kali. Backspace menghapus pintasan.

### Pintasan keyboard di aplikasi {#keyboards-app-shortcuts}

**Pintasan keyboard** > **Pintasan keyboard di aplikasi** menetapkan pintasan keyboard untuk satu aplikasi. Pintasan ini didahulukan daripada pintasan peta tombol saat aplikasi tersebut ditampilkan. Pintasan yang diatur ke **Ketuk untuk menetapkan** di suatu aplikasi membiarkan tombolnya diteruskan ke aplikasi tersebut.

1. Di **Pintasan keyboard**, pilih **Pintasan keyboard di aplikasi**.
2. Pilih **Tambahkan aplikasi**, lalu pilih aplikasinya.
3. Di bawah **Pintasan keyboard**, pilih **Tambahkan pintasan keyboard**, lalu tekan tombolnya.
4. Pilih sebuah perintah.

Layar yang sama memuat gestur untuk setiap aplikasi. Untuk gestur di aplikasi, lihat [](#gestures).

### Menemukan pintasan keyboard {#keyboards-shortcut-list}

**Tampilkan daftar pintasan keyboard** membuka daftar semua perintah beserta pintasannya yang dapat Anda telusuri. Pintasan defaultnya adalah Tombol SandFly + Shift + / di Peta tombol SandFly, dan Tombol SandFly + Q di Peta tombol ponsel berkeyboard.

**Pintasan keyboard** > **Telusuri** mencari perintah berdasarkan nama atau tombolnya di setelan. Untuk pintasan default setiap peta tombol, lihat [](#appendix-keyboard-shortcuts).

### Mode penjelajahan {#keyboards-browse-mode}

Dalam mode penjelajahan, tombol tunggal tanpa tombol SandFly memindahkan fokus SandFly, seperti pada pembaca layar komputer: di Peta tombol SandFly, H berpindah ke judul berikutnya, K ke tautan berikutnya, B ke tombol berikutnya, D ke tengara berikutnya, dan F ke kontrol berikutnya, sedangkan Shift bersama tombol tersebut bergerak mundur. Tombol panah berpindah per baris dan karakter, dan Ctrl bersama Panah Kiri atau Kanan berpindah per kata. Mode penjelajahan bekerja di konten web maupun di aplikasi.

Pintasan default untuk **Aktifkan atau nonaktifkan mode penjelajahan** adalah:

| Peta tombol | Pintasan |
| --- | --- |
| Peta tombol SandFly | Tombol SandFly ditekan dua kali |
| Peta tombol VoiceOver | Tombol SandFly + Q |
| Peta tombol NVDA | Tombol SandFly + Spasi |
| Peta tombol JAWS | Tombol SandFly + Z |
| Peta tombol Orca | Tombol SandFly + A |

SandFly memutar suara atau mengucapkan "Mode penjelajahan aktif" atau "Mode penjelajahan nonaktif".

Pada peta tombol ponsel berkeyboard, perintah yang memerlukan mode penjelajahan di peta tombol lain tetap berfungsi tanpa mode penjelajahan.

Dua setelan di **Navigasi** mengatur kapan mode penjelajahan aktif:

- **Navigasi** > **Mode penjelajahan cerdas**: menonaktifkan mode penjelajahan saat fokus berpindah ke kolom teks di konten web agar Anda dapat mengetik, lalu mengaktifkannya lagi saat fokus berpindah ke item yang bukan kolom teks. Aktif secara default.
- **Navigasi** > **Ingat mode jelajah di setiap aplikasi**: mengingat apakah Anda terakhir mengaktifkan atau menonaktifkan mode penjelajahan di setiap aplikasi. Di aplikasi tempat Anda belum pernah mengaktifkan atau menonaktifkannya, mode penjelajahan nonaktif, kecuali **Mode penjelajahan cerdas** mengaktifkannya di konten web. Nonaktif secara default.

Untuk navigasi menurut elemen web, lihat [](#web).

### Navigasi tombol panah {#keyboards-arrow-keys}

Saat navigasi tombol panah aktif, tombol panah menjalankan perintah tanpa tombol SandFly: sendirian, dua tombol ditekan bersamaan, atau bersama Ctrl atau Alt. Perintah defaultnya mengikuti tombol panah di VoiceOver pada iPhone:

| Tombol | Perintah |
| --- | --- |
| Panah Kanan, Panah Kiri | Item berikutnya, item sebelumnya |
| Panah Bawah, Panah Atas | Sesuaikan kontrol pembacaan ke bawah, ke atas |
| Panah Kiri + Panah Kanan bersamaan | **Aktifkan atau nonaktifkan navigasi tombol panah** |
| Panah Atas + Panah Bawah bersamaan | Aktifkan item |
| Panah Atas + Panah Kanan, Panah Atas + Panah Kiri bersamaan | Pilih kontrol pembacaan berikutnya, kontrol pembacaan sebelumnya |
| Ctrl + Panah Atas, Ctrl + Panah Bawah | Item pertama, item terakhir di layar |
| Alt + Panah Atas, Alt + Panah Bawah | Gulir mundur, gulir maju |
| Alt + Panah Kiri, Alt + Panah Kanan | Gulir ke kanan, gulir ke kiri |

Panah Bawah + Panah Kanan, Panah Bawah + Panah Kiri, Ctrl + Panah Kiri, dan Ctrl + Panah Kanan tidak memiliki perintah secara default.

Untuk mengaktifkan atau menonaktifkan navigasi tombol panah, tekan Panah Kiri dan Panah Kanan secara bersamaan, atau aktifkan/nonaktifkan **Pintasan keyboard** > **Navigasi tombol panah** > **Navigasi tombol panah**. **Aktifkan atau nonaktifkan navigasi tombol panah** juga merupakan perintah yang dapat Anda tetapkan ke gestur. Navigasi tombol panah nonaktif secara default, kecuali pada peta tombol ponsel berkeyboard, di mana fitur ini aktif untuk tombol panah yang dikirim oleh trackpad, seperti trackpad pada Zinwa Q25.

Untuk mengubah perintah suatu tombol panah:

1. Di **Pintasan keyboard**, buka **Navigasi tombol panah**.
2. Pilih tombol panahnya, seperti "Panah Atas + Panah Bawah".
3. Pilih perintah dari daftar, daftar yang sama seperti untuk gestur.

Tombol yang merupakan bagian dari kombinasi dua tombol yang ditekan bersamaan menjalankan perintahnya saat Anda melepaskannya, kecuali Anda menekan tombol kedua terlebih dahulu. Saat kolom teks sedang diedit, tombol panah tunggal memindahkan kursor; tombol yang ditekan bersamaan tetap menjalankan perintahnya, dan Panah Kiri + Panah Kanan menonaktifkan navigasi tombol panah setelah keduanya ditahan selama 0,4 detik.

Setiap peta tombol memiliki perintah tombol panah dan tombol alihnya sendiri. Peta tombol NVDA, JAWS, dan Orca tidak memiliki navigasi tombol panah, karena tombol panahnya langsung memindahkan fokus SandFly; di sana, perintah ini mengucapkan "Tidak ada navigasi tombol panah di peta tombol ini".

### Navigasi desktop {#keyboards-desktop}

Pada Peta tombol NVDA, JAWS, dan Orca, serta peta tombol yang disalin darinya:

- Panah Bawah dan Panah Atas berpindah ke item berikutnya dan sebelumnya. Panah Kiri dan Panah Kanan berpindah per karakter, dan bersama Ctrl berpindah per kata. Ctrl + Home dan Ctrl + End berpindah ke item pertama dan terakhir.
- Tab dan Shift + Tab memindahkan fokus input dan fokus SandFly ke item berikutnya dan sebelumnya yang dapat menerima fokus input.
- Enter mengeklik item dengan fokus SandFly, kecuali item itu memiliki fokus input.
- Escape adalah Kembali.
- Di dalam kolom teks yang sedang diedit, tombol-tombol ini diteruskan ke kolom teks.

Dalam mode penjelajahan, huruf tunggal berpindah menurut elemen, sebagaimana navigasi satu huruf, tombol navigasi cepat, dan navigasi struktural di NVDA, JAWS, dan Orca.

#### Navigasi objek {#keyboards-object-navigation}

Perintah **Navigasi objek** memindahkan fokus SandFly melalui item-item sesuai susunan aplikasi, termasuk wadah (container) yang biasanya dilewati fokus SandFly:

- **Navigasikan ke objek penampung**
- **Navigasikan ke objek pertama di dalamnya**
- **Navigasikan ke objek berikutnya**
- **Navigasikan ke objek sebelumnya**

Wadah tanpa label dibacakan sebagai "Grup" diikuti jumlah itemnya.

#### Kursor tinjauan {#keyboards-review-cursor}

Kursor tinjauan membacakan teks di layar per baris, kata, dan karakter sesuai tata letaknya, dari atas ke bawah dan kiri ke kanan, tanpa memindahkan fokus SandFly. Item yang berdampingan di layar dibacakan sebagai satu baris. Perintah **Tinjauan layar** meliputi:

- **Tinjau baris sebelumnya**, **Tinjau baris saat ini**, **Tinjau baris berikutnya**
- **Tinjau kata sebelumnya**, **Tinjau kata saat ini**, **Tinjau kata berikutnya**
- **Tinjau karakter sebelumnya**, **Tinjau karakter saat ini**, **Tinjau karakter berikutnya**
- **Tinjau baris teratas**, **Tinjau baris terbawah**, **Tinjau awal baris**, **Tinjau akhir baris**
- **Lakukan klik di kursor tinjauan**, **Lakukan klik panjang di kursor tinjauan**: mengeklik item di posisi kursor tinjauan, atau mengetuk layar di posisi tersebut.
- **Pindahkan kursor tinjauan ke fokus SandFly**, **Pindahkan fokus SandFly ke kursor tinjauan**
- **Aktifkan kursor tinjauan**, **Nonaktifkan kursor tinjauan**
- **Kenali teks di layar**: mengenali teks pada tangkapan layar dan menampilkannya untuk ditinjau, termasuk teks yang tidak dilaporkan aplikasi. Memerlukan Android 11 atau yang lebih baru.

Perintah tinjauan dimulai dari posisi fokus SandFly, kecuali kursor tinjauan sedang aktif. Saat kursor tinjauan aktif, dan saat teks yang dikenali ditampilkan, tombol-tombol berikut memindahkan dan mengeklik kursor tinjauan alih-alih diteruskan ke aplikasi:

- Panah Atas dan Panah Bawah: baris sebelumnya dan berikutnya.
- Panah Kiri dan Panah Kanan: karakter sebelumnya dan berikutnya. Dengan Ctrl: kata sebelumnya dan berikutnya.
- Home dan End: awal dan akhir baris. Dengan Ctrl: baris teratas dan terbawah.
- Page Up dan Page Down: baris teratas dan terbawah.
- Enter: klik. Shift + Enter: klik panjang.
- Escape: menutup teks yang dikenali.

Di Peta tombol JAWS, kursor tinjauan bekerja seperti kursor JAWS; di Peta tombol Orca, seperti tinjauan datar (flat review). Perintah-perintah ini memiliki pintasan di Peta tombol NVDA, JAWS, dan Orca. Di peta tombol lain, Anda dapat menetapkannya di **Pintasan keyboard**.

### Meneruskan tombol ke aplikasi {#keyboards-pass-keys}

Beberapa aplikasi menggunakan tombol yang juga digunakan SandFly. Perintah-perintah ini meneruskan tombol ke aplikasi:

- **Melewati sistem**: tombol berikutnya, atau kombinasi tombol bersamaan, yang Anda tekan setelah pintasan ini akan diteruskan ke aplikasi alih-alih ke SandFly. SandFly mengucapkan "Mengabaikan penekanan tombol berikutnya". Pintasan defaultnya adalah Tombol SandFly + Shift + Escape di Peta tombol SandFly, dan Tombol SandFly + P di Peta tombol ponsel berkeyboard.
- **Teruskan tombol tanpa tombol SandFly ke aplikasi ini**: aplikasi yang tampil menerima setiap tombol yang ditekan tanpa tombol SandFly, seperti tombol panah dan huruf mode penjelajahan, hingga Anda menjalankan perintah ini lagi di aplikasi tersebut. SandFly mengucapkan "Meneruskan tombol ke" atau "Tidak meneruskan tombol ke" diikuti nama aplikasi, dan menyimpan pilihan ini untuk setiap aplikasi. Saat kursor tinjauan aktif, kursor tinjauan tetap mengambil tombolnya. Pintasan defaultnya adalah Tombol SandFly + Shift + Spasi di Peta tombol NVDA, dan Tombol SandFly + Shift + Q di Peta tombol ponsel berkeyboard.
- **Aktifkan atau nonaktifkan input keyboard SandFly**: setiap tombol diteruskan ke Android, termasuk pintasan dengan tombol SandFly, hingga Anda menekan pintasan perintah ini lagi. SandFly mengucapkan "Input keyboard SandFly nonaktif" atau "Input keyboard SandFly aktif". Input keyboard aktif kembali saat SandFly dimulai ulang. Pintasan defaultnya adalah Tombol SandFly + Shift + K di Peta tombol SandFly, NVDA, dan JAWS, serta Tombol SandFly + Shift + P di Peta tombol ponsel berkeyboard.

Perintah-perintah ini berada di kategori **Aktivasi**. Sebuah skrip juga dapat membuat SandFly meneruskan setiap tombol ke aplikasinya; mengaktifkan kembali input keyboard SandFly akan mengakhiri hal tersebut. Lihat [](#scripts).

### Ponsel berkeyboard {#keyboards-phones}

Ponsel berkeyboard adalah ponsel dengan keyboard bawaan yang memiliki huruf, Shift, Alt, dan sering kali Sym, tetapi tanpa tombol Ctrl, Meta, atau panah: ponsel Unihertz Titan, BlackBerry KEYone, KEY2, dan KEY2 LE, serta ponsel Zinwa seperti Q25. SandFly mengenali ponsel-ponsel ini dan menggunakan **Peta tombol ponsel berkeyboard** padanya. Anda dapat memilih salah satu peta tombol ponsel berkeyboard di ponsel mana pun.

- **Peta tombol ponsel berkeyboard**: pintasan yang paling sering dipakai adalah penekanan tombol yang tidak digunakan untuk mengetik, dan bekerja di mana saja termasuk kolom teks. Tombol SandFly yang ditekan sendirian berpindah ke item berikutnya, dan Shift + Tombol SandFly ke item sebelumnya. Enter mengaktifkan item yang baru dituju fokus SandFly. Alt yang ditekan dua kali memutar atau menjeda media dan menjawab panggilan. Alt + Shift yang ditahan memilih kontrol pembacaan berikutnya. Pintasan lainnya adalah Tombol SandFly dengan huruf, seperti Tombol SandFly + J, I, dan K untuk kontrol pembacaan, serta T dan B untuk bagian atas dan bawah layar.
- **Peta tombol satu tombol ponsel berkeyboard**: tombol tunggal menjalankan perintah, seperti Spasi untuk item berikutnya dan Shift + Spasi untuk item sebelumnya, H untuk judul berikutnya, serta J, L, I, dan K untuk kontrol pembacaan. Tombol tunggal bekerja di luar kolom teks yang sedang diedit. Tombol SandFly bersama tombol-tombol ini melakukan hal yang sama di mana saja, termasuk di kolom teks, sehingga Tombol SandFly + Spasi keluar dari kolom teks. Shift + Z mengunci atau membuka kunci sentuhan.

Pada kedua peta tombol:

- Enter, saat ditekan setelah fokus SandFly berpindah ke suatu item, mengaktifkan item tersebut. Setelah Anda mengetik, Enter diteruskan ke aplikasi sehingga dapat mengirim pesan. Jika fokus SandFly berada di kolom teks yang sedang diedit, Enter diteruskan ke aplikasi.
- Perintah yang memerlukan mode penjelajahan di peta tombol lain tetap berfungsi tanpa mode penjelajahan.
- Navigasi tombol panah aktif secara default. Penekanan trackpad yang mengirim Enter, seperti pada Zinwa Q25, mengaktifkan item.
- Jika Alt menjadi tombol SandFly, Alt dengan huruf tetap mengetikkan angka atau simbolnya di dalam kolom teks yang sedang diedit.
- Pintasan dengan Sym, Fn, atau Ctrl juga berfungsi di dalam kolom teks.
- Tombol SandFly + L mengunci atau membuka kunci sentuhan pada Peta tombol ponsel berkeyboard. Lihat [](#touch).

Untuk daftar lengkap pintasan, lihat [](#appendix-keyboard-shortcuts).

#### Tombol SandFly pada ponsel berkeyboard {#keyboards-phone-sandfly-key}

Peta tombol ponsel berkeyboard menawarkan Sym, Ctrl, Shift Kanan, Fn, Alt Kanan, Alt, dan Meta sebagai tombol SandFly. Secara default, SandFly memilih tombol yang tidak dibutuhkan untuk mengetik di ponsel tersebut:

- Ctrl, pada ponsel Unihertz yang setelan keyboardnya mengatur tombol Fn agar bekerja sebagai Ctrl, kecuali Titan 2 Elite.
- Shift Kanan, pada Unihertz Titan 2 Elite, Zinwa Q25, dan ponsel BlackBerry yang memiliki tombol Shift kanan.
- Sym, pada ponsel lain yang memiliki tombol Sym.
- Alt, pada ponsel tanpa tombol Sym, seperti Unihertz Titan generasi pertama.

Jika Sym menjadi tombol SandFly, lapisan simbol keyboard tidak tersedia dari Sym. Pada Zinwa Q25, tombol berlabel Sym mengirimkan Alt Kanan. Pada BlackBerry KEY2, Fn adalah tombol Speed.

#### Setelan keyboard fisik di Mengetik {#keyboards-typing-settings}

**Mengetik** > **Keyboard fisik** ditampilkan saat keyboard fisik terhubung:

- **Tombol huruf menekan tombol keypad**: pada keyboard yang tombol hurufnya juga memuat angka, seperti pada ponsel BlackBerry, Unihertz, dan Zinwa di mana W, E, dan R adalah 1, 2, dan 3, tombol huruf menekan tombol pad PIN layar kunci, keypad panggilan (dan memutar nada keypad), serta kalkulator (di mana karakter Alt dari huruf, seperti + dan -, menekan tombol operator). Menekan huruf di layar kunci sebelum pad PIN tampil akan membukanya. Tombol dengan pengubah, tombol angka, dan tombol yang diketik ke kolom teks tidak diambil. Setelan ini aktif secara default, dan hanya ditampilkan untuk keyboard semacam itu.
- **Enter mengirim pesan**: di kolom pesan pada aplikasi perpesanan, seperti Messages, WhatsApp, Telegram, Signal, atau Slack, saat ada teks di dalamnya, Enter menekan tombol Kirim milik aplikasi. Shift + Enter dan Alt + Enter diteruskan ke aplikasi, yang mengetikkan baris baru. Ini bekerja dengan keyboard fisik apa saja, dan nonaktif secara default.
- **Keyboard SandFly**: membuka daftar keyboard di setelan Android, tempat Anda mengaktifkan Keyboard SandFly. Lihat [](#keyboards-sandfly-keyboard).
- **Ketikan tombol yang ditahan**: karakter yang diketik saat tombol ditahan dengan Keyboard SandFly.
- **Karakter tekan dua kali**: karakter yang diketik saat tombol ditekan dua kali dengan Keyboard SandFly. Lihat [](#keyboards-double-press).
- **Spasi dua kali mengetikkan titik**: dengan Keyboard SandFly, Spasi yang ditekan dua kali setelah sebuah kata mengetikkan titik dan spasi. Nonaktif secara default.
- **Setelan keyboard fisik Android**: membuka setelan keyboard fisik Android, seperti tata letak keyboard.

### Keyboard SandFly {#keyboards-sandfly-keyboard}

Keyboard SandFly adalah metode input untuk keyboard fisik. Keyboard ini tidak menampilkan tombol apa pun di layar. Tombol tetap mengetik seperti tanpa keyboard ini; Keyboard SandFly menambahkan:

- Informasi tepat mengenai apakah sebuah kolom teks menerima ketikan Anda, sehingga pintasan satu tombol dan Enter pada peta tombol ponsel berkeyboard bekerja di tempat yang tepat.
- Tombol yang ditahan yang mengetikkan karakter Alt tombol tersebut atau huruf kapitalnya.
- Penekanan dua kali yang mengetikkan karakter lain, seperti G G untuk ğ, dan titik untuk Spasi yang ditekan dua kali.
- Pencarian emoji dan daftar simbol.
- Mode pengeditan, di mana tombol tunggal memindahkan kursor serta memilih, menyalin, memotong, dan menempel.

Keyboard SandFly tidak tersedia di jam tangan dan TV.

#### Mengaktifkan Keyboard SandFly {#keyboards-turn-on-sandfly-keyboard}

1. Hubungkan keyboard, atau gunakan keyboard bawaan ponsel berkeyboard.
2. Di setelan SandFly, buka **Mengetik** > **Keyboard fisik** > **Keyboard SandFly**.
3. Aktifkan **Keyboard SandFly** di daftar keyboard.
4. Di kolom teks, beralih ke Keyboard SandFly menggunakan pengalih keyboard Android, atau dengan perintah **Ganti keyboard** yang beralih ke keyboard aktif berikutnya. **Ganti keyboard** memerlukan Android 11 atau yang lebih baru.

Saat Keyboard SandFly digunakan, tidak ada keyboard di layar yang tampil.

#### Tombol yang ditahan {#keyboards-held-keys}

**Mengetik** > **Keyboard fisik** > **Ketikan tombol yang ditahan** mengatur karakter yang diketik saat tombol karakter ditahan menggunakan Keyboard SandFly:

- **Karakter Alt**: karakter Alt dari tombol tersebut, seperti di keyboard BlackBerry, atau huruf kapitalnya jika tidak memiliki karakter Alt. Ini adalah default.
- **Huruf kapital**: huruf kapitalnya.
- **Karakter berulang**: karakter tersebut diulang, seperti tanpa Keyboard SandFly.

Tombol mengetikkan karakternya sendiri terlebih dahulu; saat Android mulai mengulangnya, Keyboard SandFly menggantinya dengan karakter tombol yang ditahan.

#### Penekanan dua kali {#keyboards-double-press}

**Mengetik** > **Keyboard fisik** > **Karakter tekan dua kali** mencantumkan tombol dan karakter yang diketik saat ditekan dua kali dengan Keyboard SandFly, seperti ğ untuk G, ö untuk O, atau ä untuk E. **Tambahkan tombol** menambahkan entri baru: masukkan karakter tombol di **Tombol** dan karakternya di **Tekan dua kali mengetikkan**. Setiap tombol memiliki opsi **Sunting** dan **Hapus**. Daftar ini kosong secara default.

Tekanan pertama mengetikkan karakter tombol tersebut. Tekanan kedua pada tombol yang sama dalam 350 milidetik, tanpa tombol lain atau perpindahan kursor di antaranya, menggantinya dengan karakter tekan dua kali. Setelah huruf kapital, seperti dengan Shift, penekanan dua kali mengetikkan huruf kapitalnya, seperti Ğ. Tombol yang tidak ada di daftar mengetik seperti biasa.

Saat **Spasi dua kali mengetikkan titik** aktif, Spasi yang ditekan dua kali setelah huruf atau angka mengganti spasi pertama dengan titik dan spasi.

Penekanan dua kali tidak berlaku di kolom sandi.

#### Menelusuri emoji dan memilih simbol {#keyboards-emoji}

**Telusuri emoji** dan **Pilih simbol** membuka daftar di dalam kolom teks yang sedang diedit:

1. Jalankan **Telusuri emoji** atau **Pilih simbol**. SandFly mengucapkan "Pencarian emoji" atau "Simbol". Karakter yang terakhir Anda pilih muncul lebih dulu.
2. Ketik kata-kata dari nama karakter, seperti "jempol ke atas". Setiap kata yang diketik harus mengawali sebuah kata dalam nama tersebut. Nama emoji mengikuti bahasa ponsel Anda.
3. Tekan tombol panah, atau Tab dan Shift + Tab, untuk berpindah melalui hasil yang cocok. SandFly membacakan setiap hasil beserta posisinya, seperti "1 dari 5".
4. Tekan Enter untuk mengetikkan karakter tersebut.

Backspace menghapus huruf terakhir yang diketik, dan menutup daftar jika tidak ada yang diketik. Kembali atau Escape menutup daftar. Jika Keyboard SandFly tidak sedang digunakan di kolom teks, perintah ini mengucapkan "Memerlukan Keyboard SandFly di kolom teks".

Pada peta tombol ponsel berkeyboard, **Telusuri emoji** adalah Tombol SandFly + O, dan **Pilih simbol** adalah Alt + Spasi saat mengedit. Pada Zinwa Q25, Alt + Spasi juga membuka daftar simbol. Di peta tombol lain, Anda dapat menetapkannya di **Pintasan keyboard**, pada kategori **Pengeditan teks**.

#### Mode pengeditan {#keyboards-editing-mode}

**Aktifkan atau nonaktifkan mode pengeditan** mengaktifkan mode pengeditan di kolom teks yang sedang diedit. SandFly mengucapkan "Mode pengeditan aktif". Dalam mode pengeditan, tombol tunggal memindahkan kursor dan mengedit alih-alih mengetik, dan SandFly membacakan setiap perpindahan:

- J dan L, atau Panah Kiri dan Panah Kanan: karakter sebelumnya dan berikutnya.
- I dan K, atau Panah Atas dan Panah Bawah: baris sebelumnya dan berikutnya.
- U dan O: kata sebelumnya dan berikutnya.
- Alt + J dan Alt + L: awal dan akhir baris. Alt + I dan Alt + K: awal dan akhir teks.
- T dan B: awal dan akhir teks.
- Shift bersama perpindahan akan memilih teks. S memulai pemilihan, dan SandFly mengucapkan "Memilih"; tekan S lagi untuk berhenti.
- A memilih semua, C menyalin, X memotong, V menempel.
- Z mengurungkan, Shift + Z mengulangi.
- R membacakan pilihan, atau membacakan baris jika tidak ada yang dipilih.
- Tombol Delete menghapus.
- Enter, Escape, atau Kembali menonaktifkan mode pengeditan.

Tombol ketik lainnya tidak melakukan apa pun dalam mode pengeditan. Mode pengeditan memerlukan Keyboard SandFly. Pada peta tombol ponsel berkeyboard, pintasannya adalah Tombol SandFly + C.

### Setelan keyboard lainnya {#keyboards-other-settings}

- **Mengetik** > **Gema keyboard** > **Keyboard fisik** mengatur apa yang diucapkan SandFly saat Anda mengetik di keyboard fisik. Lihat [](#typing).
- Setiap tombol pada keyboard fisik menghentikan ucapan, kecuali tombol pengubah seperti Shift. Ctrl yang ditekan sendirian menjeda ucapan. **Interupsi ucapan saat mengetik**, di **Ucapan**, mengatur kapan karakter yang diketik menghentikan ucapan. Lihat [](#speech).
- Jika keyboard fisik terhubung saat SandFly pertama kali dimulai, tutorial keyboard akan terbuka alih-alih tutorial gestur sentuh. Saat Anda membuka tutorial di lain waktu dengan keyboard terhubung ke perangkat berlayar sentuh, SandFly menawarkan **Tutorial gestur sentuh** dan **Tutorial keyboard**. Lihat [](#getting-started).
