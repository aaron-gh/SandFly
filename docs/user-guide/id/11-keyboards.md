## Keyboard fisik {#keyboards}

Anda dapat menggunakan SandFly dengan keyboard Bluetooth atau USB, atau dengan keyboard bawaan pada ponsel berkeyboard. SandFly menjalankan perintah dari pintasan keyboard. SandFly juga berpindah dengan tombol panah dan huruf tunggal jika peta tombol Anda menggunakannya, dan dapat membiarkan tombol diteruskan ke aplikasi yang Anda gunakan. Bab ini menjelaskan **Pintasan keyboard** di setelan SandFly dan setelan keyboard fisik di **Mengetik**. Untuk pintasan default setiap perintah, lihat [](#appendix-keyboard-shortcuts).

Untuk mempelajari pintasan keyboard langkah demi langkah, gunakan tutorial keyboard. Lihat [](#getting-started).

### Tombol SandFly {#keyboards-sandfly-key}

Sebagian besar pintasan keyboard menggunakan tombol SandFly bersama tombol lain, seperti Tombol SandFly + Panah Kanan untuk berpindah ke item berikutnya. Tombol SandFly adalah satu tombol, atau dua tombol yang ditahan bersamaan, yang Anda pilih untuk setiap peta tombol. Tombol ini dapat berupa salah satu dari tombol berikut, tergantung peta tombolnya:

- **Meta**: tombol Windows, di sebelah tombol Alt kiri. Di keyboard Apple, ini adalah tombol Command.
- **Alt**
- **Ctrl + Alt**: kedua tombol ditahan bersamaan.
- **Ctrl + Meta**: kedua tombol ditahan bersamaan.
- **Ctrl**
- **Insert**: pada kebanyakan keyboard, berada di grup enam tombol di atas tombol panah.
- **Insert Numpad**: tombol 0 pada papan angka, saat Num Lock nonaktif.
- **Sym**, **Alt Kanan**, **Shift Kanan**, dan **Fn**: tombol pada ponsel berkeyboard. Lihat [](#keyboards-phones).

Insert, Insert Numpad, Sym, Alt Kanan, Shift Kanan, dan Fn adalah tombol yang tidak diperlakukan Android sebagai tombol pengubah. SandFly mengambil tombol ini selama ditahan, sehingga tombol tersebut tidak sampai ke aplikasi.

Jika Meta menjadi tombol SandFly, menekan Meta saja satu kali membuka daftar semua aplikasi, seperti biasanya di Android. Pada peta tombol yang memakai pintasan ini, menekan tombol SandFly dua kali dengan cepat mengaktifkan atau menonaktifkan mode penjelajahan. Lihat [](#keyboards-browse-mode).

Untuk memilih tombol SandFly, lihat [](#keyboards-choose-sandfly-key).

### Peta tombol {#keyboards-keymaps}

Peta tombol adalah kumpulan pintasan keyboard. SandFly memiliki peta tombol berikut:

- **Peta tombol SandFly**: peta tombol default. Tombol SandFly-nya adalah Meta, Insert, atau Insert Numpad, dengan Meta sebagai default.
- **Peta tombol VoiceOver**: perintah keyboard VoiceOver di iPhone, dengan tombol SandFly sebagai tombol VO. Tombol SandFly-nya adalah Ctrl + Alt, Insert, atau Insert Numpad, dengan Ctrl + Alt sebagai default. Meta menggantikan Command. Dalam mode penjelajahan, tombol tunggal bergerak seperti Navigasi Cepat satu tombol di VoiceOver.
- **Peta tombol NVDA**: tata letak laptop dari NVDA yang tidak memerlukan papan angka, dengan tombol SandFly sebagai tombol NVDA. Tombol SandFly-nya adalah Insert, Insert Numpad, atau Meta, dengan Insert sebagai default.
- **Peta tombol JAWS**: kombinasi tombol desktop JAWS, ditambah tombol laptop JAWS untuk klik dan kursor. Tombol SandFly berperan sebagai tombol JAWS. Tombol SandFly-nya adalah Insert, Insert Numpad, atau Meta, dengan Insert sebagai default.
- **Peta tombol Orca**: tata letak laptop dari Orca, dengan tombol SandFly sebagai pengubah Orca. Tombol SandFly-nya adalah Insert, Insert Numpad, Meta, atau Alt, dengan Insert sebagai default.
- **Peta tombol ponsel berkeyboard** dan **Peta tombol tunggal ponsel berkeyboard**: untuk ponsel dengan keyboard bawaan yang tidak memiliki tombol Ctrl, Meta, atau panah. Lihat [](#keyboards-phones).
- **Peta tombol BlackBerry**: tombol yang mirip dengan tombol BlackBerry 10 Screen Reader, untuk ponsel berkeyboard. Mode BlackBerry memilih peta tombol ini di ponsel berkeyboard. Lihat [](#keyboards-phones) dan [](#profiles-blackberry-mode).
- Peta tombol yang Anda buat sendiri. Lihat [](#keyboards-custom-keymaps).

Pada peta tombol NVDA, JAWS, dan Orca, tombol panah dan Tab bergerak tanpa tombol SandFly, seperti di komputer. Lihat [](#keyboards-desktop).

Pada ponsel berkeyboard, peta tombol ponsel berkeyboard adalah peta tombol default. Saat pertama kali berjalan di ponsel berkeyboard, SandFly mengganti Peta tombol SandFly dengan Peta tombol ponsel berkeyboard. Penggantian ini hanya terjadi satu kali.

#### Memilih peta tombol {#keyboards-choose-keymap}

1. Di setelan SandFly, buka **Pintasan keyboard**.
2. Pilih **Pilih peta tombol**.
3. Pilih sebuah peta tombol.

SandFly mengumumkan peta tombol yang kini aktif. Setiap peta tombol menyimpan pintasannya sendiri, tombol SandFly-nya sendiri, dan setelan navigasi tombol panahnya sendiri, sehingga perubahan pada satu peta tombol tidak mengubah peta tombol lain.

#### Memilih tombol SandFly {#keyboards-choose-sandfly-key}

1. Di setelan SandFly, buka **Pintasan keyboard**.
2. Pilih **Pilih tombol SandFly**.
3. Pilih sebuah tombol.

**Pilih tombol SandFly** menetapkan tombol SandFly untuk peta tombol yang sedang digunakan. Daftar ini hanya mencantumkan tombol yang tidak merusak pintasan default peta tombol tersebut. Peta tombol buatan Anda sendiri menawarkan semua pilihan tombol SandFly. Setiap pintasan default tetap memakai tombol yang sama, hanya tombol SandFly lama diganti dengan yang baru. Pintasan yang Anda ubah disimpan terpisah untuk setiap tombol SandFly dari sebuah peta tombol.

#### Peta tombol kustom {#keyboards-custom-keymaps}

Anda dapat membuat peta tombol sendiri. Peta tombol baru dibuat sebagai salinan peta tombol yang sedang digunakan, lengkap dengan pintasan, tombol SandFly, dan cara kerja tombolnya. Contohnya, tombol panah yang berpindah seperti pada Peta tombol NVDA.

Untuk membuat peta tombol:

1. Pilih peta tombol yang akan disalin. Lihat [](#keyboards-choose-keymap).
2. Di **Pintasan keyboard**, pilih **Peta tombol baru**.
3. Masukkan nama, atau biarkan kosong untuk menggunakan nama yang ditampilkan, seperti "Salinan Peta tombol NVDA".
4. Pilih **Oke**.

Peta tombol baru langsung digunakan. Di peta tombol buatan Anda, pintasan dapat menggunakan tombol apa saja, dengan atau tanpa tombol SandFly. Pintasan tanpa tombol SandFly bekerja di mana saja, kecuali di kolom teks yang sedang diedit. Di sana, tombol diteruskan ke kolom teks. Pada peta tombol yang disalin dari Peta tombol SandFly atau VoiceOver, pintasan tanpa tombol SandFly yang memakai Ctrl atau Alt juga bekerja di kolom teks. Tombol pengubah yang ditekan sendirian selalu diteruskan ke aplikasi.

Saat peta tombol buatan Anda sedang digunakan, **Pintasan keyboard** juga memiliki:

- **Ganti nama peta tombol**: mengubah namanya.
- **Hapus peta tombol**: menghapusnya, setelah Anda konfirmasi. Peta tombol default kemudian digunakan.

#### Mengekspor dan mengimpor peta tombol {#keyboards-keymap-files}

- **Ekspor ke file**: menyimpan peta tombol yang sedang digunakan, beserta pintasan dan tombol SandFly-nya, ke file yang Anda pilih.
- **Impor dari file**: menambahkan peta tombol dari sebuah file.

Fitur ini tidak tersedia di jam tangan. Untuk format filenya, lihat [](#api-item-files).

#### Mereset peta tombol {#keyboards-reset-keymap}

**Reset peta tombol** mengembalikan semua pintasan pada peta tombol yang sedang digunakan ke tombol defaultnya, dan semua tombol panah ke perintah defaultnya. SandFly meminta konfirmasi terlebih dahulu. Reset tidak dapat diurungkan.

### Layar Pintasan keyboard {#keyboards-settings}

**Pintasan keyboard** di setelan SandFly berisi:

- **Telusuri**: menemukan perintah atau tombol panah berdasarkan nama atau tombolnya, lalu membuka pintasannya.
- **Peta tombol**: **Pilih peta tombol**, **Pilih tombol SandFly**, **Reset peta tombol**, **Lihat pintasan keyboard sistem**, **Peta tombol baru**, **Ekspor ke file**, **Impor dari file**, serta untuk peta tombol buatan Anda, **Ganti nama peta tombol** dan **Hapus peta tombol**. **Lihat pintasan keyboard sistem** membuka daftar pintasan keyboard Android dan aplikasi yang sedang digunakan.
- **Pintasan keyboard di aplikasi**: pintasan yang menjalankan perintah lain di satu aplikasi. Lihat [](#keyboards-app-shortcuts).
- **Latihan keyboard**: mengaktifkan latihan keyboard. Lihat [](#keyboards-practice).
- **Navigasi tombol panah**: pada peta tombol yang memilikinya. Lihat [](#keyboards-arrow-keys).
- **Penelusuran cepat**: **Tombol penelusuran cepat** dan **Lanjutkan dari ujung lain**. Lihat [](#keyboards-fast-search).
- Perintah-perintah, menurut kategori, masing-masing beserta pintasannya. Setiap kategori dapat dibuka dan ditutup. Perintah yang pintasannya hanya bekerja dalam mode penjelajahan memiliki keterangan "dalam mode penjelajahan" setelah namanya, seperti "Navigasi ke judul berikutnya dalam mode penjelajahan".

Anda hanya dapat mengubah pintasan dan mereset peta tombol saat SandFly aktif.

Anda juga dapat melihat dan mengubah pintasan keyboard suatu perintah di layarnya sendiri pada **Perintah**. Lihat [](#commands).

### Mengubah pintasan keyboard {#keyboards-change-shortcut}

1. Di setelan SandFly, buka **Pintasan keyboard**.
2. Buka kategori perintah, atau pilih **Telusuri** lalu ketik namanya.
3. Pilih perintah tersebut.
4. Tekan tombol baru.
5. Tekan Enter, atau pilih **Simpan**.

Di dalam dialog:

- Backspace menghapus pintasan, sehingga perintah tidak memiliki pintasan. **Hapus** melakukan hal yang sama.
- Ctrl + Backspace menetapkan kembali pintasan default, di Peta tombol SandFly dan VoiceOver serta di peta tombol yang disalin darinya.
- Escape, atau **Batal**, menutup dialog tanpa perubahan.

Jika perintah lain sudah menggunakan tombol tersebut, SandFly menampilkan "Saat ini ditetapkan ke" beserta nama perintah itu. Saat Anda menyimpan, dialog **Tombol sudah digunakan** menanyakan apakah tombol akan diambil dari perintah tersebut. Pilih **Oke** untuk menetapkannya ke perintah yang sedang Anda ubah.

Pintasan untuk **Aktifkan atau nonaktifkan mode penjelajahan** juga dapat berupa tombol SandFly yang ditekan dua kali dalam setengah detik. Ctrl + Alt dan Ctrl + Meta tidak dapat ditekan dua kali.

#### Pintasan dua tombol berurutan {#keyboards-sequences}

Pada Peta tombol SandFly dan Peta tombol VoiceOver, serta peta tombol yang disalin darinya, pintasan dapat berupa Tombol SandFly + R atau Tombol SandFly + O diikuti tombol ketiga, seperti Tombol SandFly + O, lalu H. Tekan tombol ketiga dalam 3 detik, dengan atau tanpa tombol SandFly. Tombol ketiga tidak boleh berupa Escape, Backspace, Enter, atau tombol pengubah.

Untuk merekam pintasan seperti ini, tekan Tombol SandFly + R atau Tombol SandFly + O, lalu tombol ketiga.

#### Pintasan yang hanya bekerja saat mengedit {#keyboards-while-editing}

Pilih **Hanya saat mengedit** di dialog pintasan untuk pintasan yang hanya bekerja saat kolom teks sedang diedit. Pintasan semacam ini ditekan tanpa tombol SandFly, dan SandFly mengambil tombolnya sebelum sampai ke kolom teks. Di luar kolom teks, tombol bekerja seperti biasa, seolah tidak ada pintasan. Pintasan ini ditampilkan dengan keterangan "saat mengedit" setelah tombolnya, seperti "Alt + Spasi saat mengedit".

#### Pintasan yang hanya bekerja dalam mode penjelajahan {#keyboards-in-browse-mode}

Pada peta tombol ponsel berkeyboard, pilih **Hanya dalam mode penjelajahan** di dialog pintasan untuk pintasan yang hanya bekerja dalam mode penjelajahan. Pintasan semacam ini ditekan tanpa tombol SandFly. Dalam mode penjelajahan, pintasan ini didahulukan daripada pintasan lain dengan tombol yang sama tanpa **Hanya dalam mode penjelajahan**. Pintasan lain itu kemudian dijalankan dengan menekan tombol SandFly bersama tombol tersebut. Di luar mode penjelajahan, tombol bekerja seperti biasa, seolah tidak ada pintasan. Pintasan ini ditampilkan dengan keterangan "dalam mode penjelajahan" setelah tombolnya, seperti "B dalam mode penjelajahan".

#### Penekanan tombol pada peta tombol ponsel berkeyboard {#keyboards-presses}

Pada peta tombol ponsel berkeyboard, pintasan juga dapat berupa:

- Tombol pengubah yang ditekan tanpa tombol lain, seperti Sym saja atau Shift + Sym. Penekanan seperti ini diteruskan ke aplikasi, kecuali jika ditetapkan sebagai pintasan.
- Tombol, atau tombol pengubah, yang ditekan dua kali dengan cepat, seperti Alt dua kali. Tekanan pertama diteruskan ke aplikasi seperti biasa, sedangkan tekanan kedua menjalankan pintasan.
- Tombol pengubah yang ditahan tanpa tombol lain selama setengah detik, seperti Alt + Shift ditahan.
- Tombol lain yang ditahan, seperti K ditahan. Saat Anda mengetik, tombol yang ditahan tetap mengetik seperti biasa.

Untuk merekamnya, tekan tombol dengan cara yang sama di dialog pintasan. Pada peta tombol ini, Enter yang ditekan sekali menyimpan pintasan sesaat kemudian, sedangkan Enter yang ditekan dua kali merekam Enter dua kali. Backspace menghapus pintasan.

### Pintasan keyboard di aplikasi {#keyboards-app-shortcuts}

**Pintasan keyboard** > **Pintasan keyboard di aplikasi** menetapkan pintasan keyboard untuk satu aplikasi. Selama aplikasi tersebut ditampilkan, pintasan ini didahulukan daripada pintasan peta tombol. Jika pintasan diatur ke **Tidak ditetapkan** di suatu aplikasi, tombolnya diteruskan ke aplikasi tersebut.

1. Di **Pintasan keyboard**, pilih **Pintasan keyboard di aplikasi**.
2. Pilih **Tambahkan aplikasi**, lalu pilih aplikasinya.
3. Di bawah **Pintasan keyboard**, pilih **Tambahkan pintasan keyboard**, tekan tombolnya, lalu pilih **Simpan**.
4. Pilih kategori, lalu perintah, atau pilih **Tidak ditetapkan**.

**Tambahkan pintasan keyboard** hanya tersedia saat SandFly aktif. Pilih pintasan untuk **Pilih perintah** atau **Hapus**. **Hapus aplikasi** menghapus gerakan dan pintasan aplikasi tersebut.

Layar yang sama memuat gerakan untuk setiap aplikasi. Untuk gerakan di aplikasi, lihat [](#gestures).

### Menemukan pintasan keyboard {#keyboards-shortcut-list}

**Tampilkan daftar pintasan keyboard** membuka daftar semua perintah beserta pintasannya. Anda dapat menelusuri daftar ini. Pintasan defaultnya adalah Tombol SandFly + Shift + / di Peta tombol SandFly, VoiceOver, NVDA, JAWS, dan Orca. Di Peta tombol ponsel berkeyboard dan Peta tombol BlackBerry, pintasannya Tombol SandFly + Q, dan di Peta tombol satu tombol ponsel berkeyboard, pintasannya Q.

**Pintasan keyboard** > **Telusuri** mencari perintah berdasarkan nama atau tombolnya di setelan. Untuk pintasan default setiap peta tombol, lihat [](#appendix-keyboard-shortcuts).

### Latihan keyboard {#keyboards-practice}

Saat latihan keyboard aktif, SandFly mengucapkan setiap tombol yang Anda tekan beserta perintahnya, tetapi tidak menjalankan perintah apa pun. Tombol tidak diteruskan ke aplikasi. Gunakan fitur ini untuk mempelajari tombol pada keyboard dan pintasan di peta tombol Anda.

- Tombol diucapkan sesuai penamaannya di daftar pintasan keyboard, diikuti perintahnya, seperti "Shift Kanan + W, Ucapkan judul jendela". Tombol tanpa perintah diucapkan sendirian.
- Tombol pengubah diucapkan saat Anda menekannya, beserta perintah untuk tombol pengubah itu jika ditekan tanpa tombol lain. Tombol SandFly yang ditekan tanpa tombol lain juga diucapkan sebagai tombol SandFly, seperti "Shift Kanan, Tombol SandFly, Item berikutnya".
- Tombol yang ditekan dua kali, tombol yang ditahan, dan tombol kedua dari pintasan dua tombol berurutan diucapkan beserta perintahnya, seperti "Alt dua kali" atau "Alt + Shift ditahan".
- Saat navigasi tombol panah aktif, tombol panah diucapkan beserta perintah navigasi tombol panahnya.
- Tombol yang ditahan diucapkan sekali.

Untuk mengaktifkan latihan keyboard, pilih **Pintasan keyboard** > **Latihan keyboard** atau **Bantuan & masukan** > **Latihan keyboard**, atau tekan pintasan **Aktifkan atau nonaktifkan latihan keyboard**: Tombol SandFly + K di Peta tombol VoiceOver, Tombol SandFly + 1 di Peta tombol NVDA dan JAWS, Tombol SandFly + H di Peta tombol Orca, dan Tombol SandFly + Shift + K di peta tombol ponsel berkeyboard. Peta tombol SandFly tidak memiliki pintasan default. SandFly mengucapkan "Latihan keyboard aktif".

Untuk menonaktifkannya, tekan pintasan itu lagi, Kembali, atau Escape. SandFly mengucapkan "Latihan keyboard nonaktif". Latihan keyboard juga nonaktif saat SandFly dimulai ulang atau ditangguhkan.

**Aktifkan atau nonaktifkan latihan keyboard** berada di kategori **SandFly**, sehingga Anda juga dapat menetapkannya ke gerakan atau menambahkannya ke menu SandFly. Tombol volume yang ditekan tanpa tombol SandFly mengubah volume seperti biasa. Pelajaran **Latihan keyboard** di tutorial keyboard adalah hal yang berbeda. Pelajaran itu hanya mengucapkan pintasan keyboard di layar tutorial. Untuk membukanya, pilih **Daftar isi** di tutorial keyboard, atau jalankan **Berlatih pintasan keyboard**, Tombol SandFly + 0 di Peta tombol SandFly.

### Mode penjelajahan {#keyboards-browse-mode}

Dalam mode penjelajahan, tombol tunggal tanpa tombol SandFly memindahkan fokus SandFly, seperti pada pembaca layar komputer. Di Peta tombol SandFly, H berpindah ke judul berikutnya, K ke tautan berikutnya, B ke tombol berikutnya, D ke penunjuk berikutnya, dan F ke kontrol berikutnya. Shift bersama tombol tersebut berpindah mundur. Tombol panah berpindah per baris dan karakter, dan Ctrl bersama Panah Kiri atau Kanan berpindah per kata. Mode penjelajahan bekerja di konten web maupun di aplikasi.

Pintasan default untuk **Aktifkan atau nonaktifkan mode penjelajahan** adalah:

| Peta tombol | Pintasan |
| --- | --- |
| Peta tombol SandFly | Tombol SandFly ditekan dua kali |
| Peta tombol VoiceOver | Tombol SandFly + Q |
| Peta tombol NVDA | Tombol SandFly + Spasi |
| Peta tombol JAWS | Tombol SandFly + Z |
| Peta tombol Orca | Tombol SandFly + A |
| Peta tombol satu tombol ponsel berkeyboard | Tombol SandFly ditekan dua kali, atau Tombol SandFly + Q jika Alt menjadi tombol SandFly |

SandFly memutar suara atau mengucapkan "Mode penjelajahan aktif" atau "Mode penjelajahan nonaktif".

Pada peta tombol ponsel berkeyboard, perintah yang memerlukan mode penjelajahan di peta tombol lain tetap berfungsi tanpa mode penjelajahan. Pada Peta tombol satu tombol ponsel berkeyboard, mode penjelajahan mengubah fungsi huruf. B, C, D, I, K, L, R, T, U, V, X, dan tombol angka 1 sampai 6 berpindah seperti dalam mode penjelajahan Peta tombol SandFly. H, F, E, dan G berpindah per judul, kontrol, kolom teks, dan gambar, baik di dalam maupun di luar mode penjelajahan. Tombol SandFly bersama salah satu huruf ini menjalankan pintasannya di luar mode penjelajahan, seperti Tombol SandFly + B untuk bagian bawah layar dan Tombol SandFly + K untuk berpindah menurut kontrol pembacaan. K dan Shift + K dalam mode penjelajahan adalah **Berpindah ke tautan berikutnya, tombol kedua** dan **Berpindah ke tautan sebelumnya, tombol kedua** di **Pintasan keyboard**. Lihat [](#keyboards-phones).

Dua setelan di **Navigasi** mengatur kapan mode penjelajahan aktif:

- **Navigasi** > **Mode penjelajahan cerdas**: menonaktifkan mode penjelajahan saat fokus berpindah ke kolom teks di konten web agar Anda dapat mengetik. Mode penjelajahan aktif lagi saat fokus berpindah ke item yang bukan kolom teks. Aktif secara default. Saat navigasi tombol panah aktif, dan pada peta tombol ponsel berkeyboard, berpindah ke kolom teks tidak memberinya fokus input. Akibatnya, mode penjelajahan tetap aktif sampai Anda mengaktifkan kolom tersebut.
- **Navigasi** > **Ingat mode penjelajahan di setiap aplikasi**: mengingat apakah terakhir kali Anda mengaktifkan atau menonaktifkan mode penjelajahan di setiap aplikasi. Di aplikasi yang belum pernah Anda atur, mode penjelajahan nonaktif, kecuali **Mode penjelajahan cerdas** mengaktifkannya di konten web. Nonaktif secara default.

Untuk navigasi menurut elemen web, lihat [](#web).

#### Penelusuran cepat {#keyboards-fast-search}

Dalam mode penjelajahan, tombol penelusuran cepat bersama huruf atau angka memindahkan fokus SandFly ke item berikutnya yang diawali huruf atau angka tersebut. Shift bersama kedua tombol itu berpindah ke item sebelumnya. Huruf besar-kecil dan aksen tidak berpengaruh. Misalnya, E menemukan "Email" dan "Écran".

Untuk memilih tombolnya, buka **Pintasan keyboard** > **Penelusuran cepat** > **Tombol penelusuran cepat**. Nonaktif secara default. Daftarnya berisi Alt, Ctrl, dan Meta (masing-masing kiri atau kanan), serta Sym dan Fn. Tombol yang menjadi bagian dari tombol SandFly peta tombol tersebut tidak dicantumkan. Jika Anda mengganti tombol SandFly menjadi tombol yang mencakup tombol penelusuran cepat, penelusuran cepat dinonaktifkan untuk peta tombol tersebut.

Penelusuran cepat tidak bekerja di kolom teks tempat Anda sedang mengetik. Selama tombol penelusuran cepat ditahan, huruf dan angkanya tidak menjalankan pintasan lain.

**Pintasan keyboard** > **Penelusuran cepat** > **Lanjutkan dari ujung lain**: jika setelah fokus SandFly tidak ada lagi item yang diawali huruf tersebut, penelusuran dilanjutkan dari bagian atas layar, atau dari bagian bawah saat berpindah mundur. Aktif secara default. Jika tidak ada item yang ditemukan, SandFly mengucapkan "Tidak ditemukan".

### Navigasi tombol panah {#keyboards-arrow-keys}

Saat navigasi tombol panah aktif, tombol panah menjalankan perintah tanpa tombol SandFly. Tombol panah dapat ditekan sendiri, dua sekaligus, atau bersama Ctrl atau Alt. Perintah defaultnya mengikuti tombol panah di VoiceOver pada iPhone:

| Tombol | Perintah |
| --- | --- |
| Panah Kanan, Panah Kiri | Item berikutnya, item sebelumnya |
| Panah Bawah, Panah Atas | Sesuaikan kontrol pembacaan ke bawah, ke atas |
| Panah Kiri + Panah Kanan bersamaan | **Aktifkan atau nonaktifkan navigasi tombol panah** |
| Panah Atas + Panah Bawah bersamaan | Aktifkan item |
| Panah Atas + Panah Kanan, Panah Atas + Panah Kiri bersamaan | Pilih kontrol pembacaan berikutnya, kontrol pembacaan sebelumnya |
| Ctrl + Panah Atas, Ctrl + Panah Bawah | Item pertama, item terakhir di layar |
| Alt + Panah Atas, Alt + Panah Bawah | Gulir mundur, gulir maju |
| Alt + Panah Kiri, Alt + Panah Kanan | Gulir ke kanan, gulir ke kiri |

Panah Bawah + Panah Kanan, Panah Bawah + Panah Kiri, Ctrl + Panah Kiri, dan Ctrl + Panah Kanan tidak memiliki perintah secara default.

Untuk mengaktifkan atau menonaktifkan navigasi tombol panah, tekan Panah Kiri dan Panah Kanan secara bersamaan, atau aktifkan atau nonaktifkan **Pintasan keyboard** > **Navigasi tombol panah** > **Navigasi tombol panah**. **Aktifkan atau nonaktifkan navigasi tombol panah** juga merupakan perintah yang dapat Anda tetapkan ke gerakan. Navigasi tombol panah nonaktif secara default. Pengecualiannya adalah peta tombol ponsel berkeyboard. Di sana, fitur ini aktif untuk tombol panah yang dikirim trackpad, seperti trackpad pada Zinwa Q25.

Untuk mengubah perintah suatu tombol panah:

1. Di **Pintasan keyboard**, buka **Navigasi tombol panah**.
2. Pilih tombol panahnya, seperti "Panah Atas + Panah Bawah".
3. Pilih perintah dari daftar, daftar yang sama seperti untuk gerakan.

Jika sebuah tombol juga menjadi bagian dari kombinasi dua tombol, tombol itu menjalankan perintahnya saat Anda melepaskannya, kecuali Anda sempat menekan tombol kedua. Saat kolom teks sedang diedit, tombol panah tunggal memindahkan kursor. Tombol yang ditekan bersamaan tetap menjalankan perintahnya, dan Panah Kiri + Panah Kanan menonaktifkan navigasi tombol panah setelah keduanya ditahan selama 0,4 detik.

Saat navigasi tombol panah aktif dan Anda berpindah ke kolom teks, SandFly membacakan kolom itu tanpa memberinya fokus input. Tombol panah tetap berpindah melewatinya, bahkan jika aplikasi sudah memberi kolom tersebut fokus input. Kolom mulai diedit setelah Anda mengaktifkannya, misalnya dengan Panah Atas + Panah Bawah, atau setelah Anda mengetik di dalamnya. Pada peta tombol ponsel berkeyboard, Enter juga mengaktifkannya. Jika layar baru terbuka dengan fokus SandFly pada kolom teks yang memiliki fokus input, kolom itu langsung dalam keadaan diedit. Pada peta tombol ponsel berkeyboard, jika fokus SandFly berada di item lain pada layar baru, huruf yang Anda ketik masuk ke kolom teks yang memiliki fokus input. Setelah Anda mengetik, tombol panah berpindah ke kolom tersebut.

Setiap peta tombol memiliki perintah tombol panah dan tombol alihnya sendiri. Peta tombol NVDA, JAWS, dan Orca tidak memiliki navigasi tombol panah, karena tombol panahnya langsung memindahkan fokus SandFly. Pada peta tombol tersebut, perintah ini mengucapkan "Tidak ada navigasi tombol panah di peta tombol ini".

### Navigasi desktop {#keyboards-desktop}

Pada Peta tombol NVDA, JAWS, dan Orca, serta peta tombol yang disalin darinya:

- Panah Bawah dan Panah Atas berpindah ke item berikutnya dan sebelumnya. Panah Kiri dan Panah Kanan berpindah per karakter, dan bersama Ctrl berpindah per kata. Ctrl + Home dan Ctrl + End berpindah ke item pertama dan terakhir.
- Tab dan Shift + Tab memindahkan fokus input dan fokus SandFly ke item berikutnya dan sebelumnya yang dapat menerima fokus input.
- Enter mengeklik item dengan fokus SandFly, kecuali item itu memiliki fokus input.
- Escape adalah Kembali.
- Di dalam kolom teks yang sedang diedit, tombol-tombol ini diteruskan ke kolom teks.

Dalam mode penjelajahan, huruf tunggal berpindah menurut elemen, seperti navigasi satu huruf di NVDA, tombol navigasi cepat di JAWS, dan navigasi struktural di Orca.

Ctrl + Panah Bawah dan Ctrl + Panah Atas berpindah ke paragraf berikutnya dan sebelumnya. Di Peta tombol NVDA, P dan Shift + P juga melakukannya dalam mode penjelajahan. Keduanya tercantum sebagai **Berpindah ke paragraf berikutnya, tombol kedua** dan **Berpindah ke paragraf sebelumnya, tombol kedua** di **Pintasan keyboard**, tempat Anda dapat mengubahnya atau menetapkannya di peta tombol lain.

#### Navigasi objek {#keyboards-object-navigation}

Perintah **Navigasi objek** memindahkan fokus SandFly melalui item sesuai susunan di dalam aplikasi, termasuk wadah (container) yang biasanya dilewati fokus SandFly:

- **Pindah ke objek penampung**
- **Pindah ke objek pertama di dalamnya**
- **Pindah ke objek berikutnya**
- **Pindah ke objek sebelumnya**

Wadah tanpa label dibacakan sebagai "Grup" diikuti jumlah itemnya.

#### Kursor tinjauan {#keyboards-review-cursor}

Kursor tinjauan membacakan teks di layar per baris, kata, dan karakter sesuai tata letaknya, dari atas ke bawah dan kiri ke kanan, tanpa memindahkan fokus SandFly. Item yang berdampingan di layar dibacakan sebagai satu baris. Perintah **Tinjauan layar** meliputi:

- **Tinjau baris sebelumnya**, **Tinjau baris saat ini**, **Tinjau baris berikutnya**
- **Tinjau kata sebelumnya**, **Tinjau kata saat ini**, **Tinjau kata berikutnya**
- **Tinjau karakter sebelumnya**, **Tinjau karakter saat ini**, **Tinjau karakter berikutnya**
- **Tinjau baris teratas**, **Tinjau baris terbawah**, **Tinjau awal baris**, **Tinjau akhir baris**
- **Klik di kursor tinjauan**, **Klik lama di kursor tinjauan**: mengeklik item di posisi kursor tinjauan, atau menyentuh layar di posisi tersebut.
- **Pindahkan kursor tinjauan ke fokus SandFly**, **Pindahkan fokus SandFly ke kursor tinjauan**
- **Aktifkan kursor tinjauan**, **Nonaktifkan kursor tinjauan**
- **Kenali teks di layar**: mengenali teks pada tangkapan layar dan menampilkannya untuk ditinjau, termasuk teks yang tidak dilaporkan aplikasi. Memerlukan Android 11 atau yang lebih baru.

Perintah tinjauan dimulai dari posisi fokus SandFly, kecuali kursor tinjauan sedang aktif. Saat kursor tinjauan aktif, dan saat teks yang dikenali ditampilkan, tombol-tombol berikut menggerakkan kursor tinjauan dan mengeklik di posisinya, bukan diteruskan ke aplikasi:

- Panah Atas dan Panah Bawah: baris sebelumnya dan berikutnya.
- Panah Kiri dan Panah Kanan: karakter sebelumnya dan berikutnya. Dengan Ctrl: kata sebelumnya dan berikutnya.
- Home dan End: awal dan akhir baris. Dengan Ctrl: baris teratas dan terbawah.
- Page Up dan Page Down: baris teratas dan terbawah.
- Enter: klik. Shift + Enter: klik panjang.
- Escape: menutup teks yang dikenali.

Di Peta tombol JAWS, kursor tinjauan bekerja seperti kursor JAWS. Di Peta tombol Orca, kursor tinjauan bekerja seperti tinjauan datar (flat review). Perintah-perintah ini memiliki pintasan di Peta tombol NVDA, JAWS, dan Orca. Di peta tombol lain, Anda dapat menetapkannya di **Pintasan keyboard**.

### Meneruskan tombol ke aplikasi {#keyboards-pass-keys}

Beberapa aplikasi menggunakan tombol yang juga digunakan SandFly. Perintah-perintah ini meneruskan tombol ke aplikasi:

- **Teruskan ke sistem**: tombol berikutnya, atau kombinasi tombol berikutnya, yang Anda tekan setelah pintasan ini diteruskan ke aplikasi, bukan ke SandFly. SandFly mengucapkan "Mengabaikan penekanan tombol berikutnya".
- **Teruskan tombol tanpa tombol SandFly ke aplikasi ini**: aplikasi yang tampil menerima setiap tombol yang ditekan tanpa tombol SandFly, seperti tombol panah dan huruf mode penjelajahan, hingga Anda menjalankan perintah ini lagi di aplikasi tersebut. SandFly mengucapkan "Meneruskan tombol ke" atau "Tidak meneruskan tombol ke" diikuti nama aplikasi, dan mengingat pilihan ini untuk setiap aplikasi. Saat kursor tinjauan aktif, kursor tinjauan tetap mengambil tombol-tombolnya.
- **Aktifkan atau nonaktifkan input keyboard SandFly**: setiap tombol diteruskan ke Android, termasuk pintasan dengan tombol SandFly, hingga Anda menekan pintasan perintah ini lagi. SandFly mengucapkan "Input keyboard SandFly nonaktif" atau "Input keyboard SandFly aktif". Input keyboard aktif kembali saat SandFly dimulai ulang.

Pintasan default-nya adalah:

| Peta tombol | Melewati sistem | Teruskan tombol tanpa tombol SandFly ke aplikasi ini | Aktifkan atau nonaktifkan input keyboard SandFly |
| --- | --- | --- | --- |
| Peta tombol SandFly | Tombol SandFly + Shift + Escape | Tidak ada | Tombol SandFly + Shift + K |
| Peta tombol VoiceOver | Tidak ada | Tidak ada | Tombol SandFly + Shift + ; |
| Peta tombol NVDA | Tombol SandFly + F2 | Tombol SandFly + Shift + Spasi | Tombol SandFly + Shift + K |
| Peta tombol JAWS | Tombol SandFly + 3 | Tombol SandFly + Shift + Z | Tombol SandFly + Shift + K |
| Peta tombol Orca | Tombol SandFly + Backspace | Tombol SandFly + Shift + A | Tombol SandFly + Shift + ; |
| Peta tombol ponsel berkeyboard | Tombol SandFly + P | Tombol SandFly + Shift + Q | Tombol SandFly + Shift + P |
| Peta tombol satu tombol ponsel berkeyboard | Tombol SandFly + P | Shift + Q | Tombol SandFly + Shift + P |

Perintah-perintah ini berada di kategori **Aktivasi**. Sebuah skrip juga dapat membuat SandFly meneruskan setiap tombol ke aplikasi skrip itu. Untuk mengakhirinya, aktifkan kembali input keyboard SandFly. Lihat [](#scripts).

### Menahan sentuhan {#keyboards-touch-hold}

**Tahan sentuhan pada item yang difokuskan** menyentuh bagian tengah item yang difokuskan, seperti yang dilakukan jari, lalu menahan sentuhan itu selama yang Anda inginkan. Gunakan perintah ini untuk tombol yang bekerja selama jari tetap berada di atasnya, seperti tombol pesan suara di Telegram. Perekaman berjalan selama sentuhan ditahan, dan pesan dikirim saat sentuhan dilepas. **Sentuh lama** tidak melakukan hal ini.

- Tahan tombolnya: sentuhan dimulai dan tetap ditahan selama Anda menahan tombol. Sentuhan dilepas saat Anda melepas tombol terakhir dari pintasan, seperti V. Tombol SandFly boleh dilepas lebih dulu. SandFly tidak mengucapkan apa pun.
- Tekan dan lepas tombolnya dalam setengah detik: sentuhan tetap ditahan meskipun tombol sudah dilepas. SandFly mengucapkan "Sentuhan ditahan". Untuk melepasnya, tekan pintasan itu lagi, Kembali, atau Escape. SandFly mengucapkan "Sentuhan dilepas".

Pintasan default-nya adalah Tombol SandFly + V pada peta tombol ponsel berkeyboard. Peta tombol lain tidak memiliki pintasan default untuk perintah ini. Selama sentuhan ditahan, tombol lain bekerja seperti biasa, dan sentuhan di seluruh layar diteruskan langsung ke aplikasi. Sentuhan dilepas setelah 10 menit, saat item tidak lagi ada di layar, atau saat SandFly dijeda. Sentuhan lain yang dikirim ke layar, seperti **Aktifkan dengan ketukan**, membatalkannya.

Perintah ini berada di kategori **Aktivasi**, sehingga Anda juga dapat menetapkannya ke gerakan atau menambahkannya ke menu SandFly. Jika dijalankan dengan cara itu, sentuhan tetap ditahan sampai Anda menjalankan perintah itu lagi atau menekan Kembali atau Escape. Perintah ini memerlukan Android 11 atau yang lebih baru. Pada versi sebelumnya, dan saat item tidak ada di layar, SandFly mengucapkan "Tidak tersedia". Jika tidak ada item yang memiliki fokus, SandFly mengucapkan "Tidak ada item yang difokuskan".

### Ponsel berkeyboard {#keyboards-phones}

Ponsel berkeyboard adalah ponsel dengan keyboard bawaan yang memiliki huruf, Shift, Alt, dan sering kali Sym, tetapi tanpa tombol Ctrl, Meta, atau panah: ponsel Unihertz Titan, BlackBerry KEYone, KEY2, dan KEY2 LE, serta ponsel Zinwa seperti Q25. SandFly mengenali ponsel-ponsel ini dan menggunakan **Peta tombol ponsel berkeyboard** padanya. Anda dapat memilih salah satu peta tombol ponsel berkeyboard di ponsel mana pun.

- **Peta tombol ponsel berkeyboard**: pintasan yang paling sering dipakai adalah penekanan tombol yang tidak digunakan untuk mengetik. Pintasan ini bekerja di mana saja, termasuk di kolom teks. Tombol SandFly yang ditekan tanpa tombol lain berpindah ke item berikutnya, dan Shift + Tombol SandFly ke item sebelumnya. Enter mengaktifkan item yang baru dituju fokus SandFly. Alt yang ditekan dua kali memutar atau menjeda media dan menjawab panggilan. Alt + Shift yang ditahan memilih kontrol pembacaan berikutnya. Pintasan lainnya adalah Tombol SandFly dengan huruf, seperti Tombol SandFly + J, I, dan K untuk kontrol pembacaan, serta T dan B untuk bagian atas dan bawah layar.
- **Peta tombol BlackBerry**: Peta tombol ponsel berkeyboard dengan tombol yang mirip dengan tombol BlackBerry 10 Screen Reader untuk keyboard eksternal, dengan tombol SandFly menggantikan Ctrl. Tombol SandFly + A membaca dari atas, dan Tombol SandFly + Shift + A dari item yang difokuskan. Tombol SandFly + Enter mengucapkan item yang difokuskan. Tombol SandFly + S menjeda ucapan, dan Tombol SandFly + Shift + S menyembunyikan atau menampilkan layar. Tombol SandFly + . mengucapkan judul layar. Tombol SandFly + Shift + T memulai Tugas cepat. Lihat [](#gestures-quick-tasks). Tombol panah, seperti dari trackpad Zinwa Q25, berpindah menurut setelan navigasi dengan Kanan dan Kiri, serta memilih setelan navigasi berikutnya dan sebelumnya dengan Atas dan Bawah. Pintasan Peta tombol ponsel berkeyboard yang sebelumnya memakai tombol-tombol tersebut dipindahkan: sentuh lama ke Tombol SandFly + Shift + Enter, **Telusuri di layar** ke Tombol SandFly + Shift + Spasi, **Buka setelan SandFly** ke Tombol SandFly + Shift + O, dan **Deskripsikan gambar** ke Tombol SandFly + Z.
- **Peta tombol tunggal ponsel berkeyboard**: tombol tunggal menjalankan perintah, seperti Spasi untuk item berikutnya dan Shift + Spasi untuk item sebelumnya, H untuk judul berikutnya, serta J, L, I, dan K untuk kontrol pembacaan. Tombol tunggal bekerja di luar kolom teks yang sedang diedit. Tombol SandFly bersama tombol-tombol ini melakukan hal yang sama di mana saja, termasuk di kolom teks. Misalnya, Tombol SandFly + Spasi berpindah keluar dari kolom teks. Shift + Z mengunci atau membuka kunci sentuhan. Tombol SandFly yang ditekan dua kali mengaktifkan atau menonaktifkan mode penjelajahan. Dalam mode penjelajahan, huruf berpindah menurut elemen seperti di Peta tombol SandFly, misalnya B ke tombol berikutnya dan K ke tautan berikutnya. Tombol SandFly bersama huruf menjalankan pintasan huruf itu di luar mode penjelajahan, misalnya Tombol SandFly + T untuk bagian atas layar. Lihat [](#keyboards-browse-mode).

Pada ketiga peta tombol:

- Jika Anda menekan Enter setelah fokus SandFly berpindah ke suatu item, Enter mengaktifkan item tersebut. Setelah Anda mengetik, Enter diteruskan ke aplikasi sehingga dapat mengirim pesan. Jika fokus SandFly berada di kolom teks yang sedang diedit, Enter diteruskan ke aplikasi. Pada kolom teks yang baru dituju fokus SandFly, Enter mengaktifkan kolom tersebut, bahkan jika kolom itu sudah memiliki fokus input.
- Perintah yang memerlukan mode penjelajahan di peta tombol lain tetap berfungsi tanpa mode penjelajahan.
- Navigasi tombol panah aktif secara default. Penekanan trackpad yang mengirim Enter, seperti pada Zinwa Q25, mengaktifkan item.
- Jika Alt menjadi tombol SandFly, Alt dengan huruf tetap mengetikkan angka atau simbolnya di dalam kolom teks yang sedang diedit.
- Pintasan dengan Sym, Fn, atau Ctrl juga berfungsi di dalam kolom teks.
- Tombol SandFly + L mengunci atau membuka kunci sentuhan pada Peta tombol ponsel berkeyboard dan Peta tombol BlackBerry, dan Shift + Z pada Peta tombol satu tombol ponsel berkeyboard. Lihat [](#touch).
- Tombol SandFly + V menahan sentuhan pada item yang difokuskan, seperti tombol pesan suara di aplikasi perpesanan. Lihat [](#keyboards-touch-hold).
- Tombol SandFly + Y mengeja kolom sandi yang sedang diedit. Lihat [](#keyboards-passwords).

Untuk daftar lengkap pintasan, lihat [](#appendix-keyboard-shortcuts).

#### Tombol SandFly pada ponsel berkeyboard {#keyboards-phone-sandfly-key}

Peta tombol ponsel berkeyboard dan Peta tombol BlackBerry menawarkan Sym, Ctrl, Shift Kanan, Fn, Alt Kanan, Alt, dan Meta sebagai tombol SandFly. Secara default, SandFly memilih tombol yang tidak dibutuhkan untuk mengetik di ponsel tersebut:

- Ctrl, pada ponsel Unihertz yang setelan keyboardnya mengatur tombol Fn agar bekerja sebagai Ctrl, kecuali Titan 2 Elite.
- Shift Kanan, pada Unihertz Titan 2 Elite, Zinwa Q25, dan ponsel BlackBerry yang memiliki tombol Shift kanan.
- Sym, pada ponsel lain yang memiliki tombol Sym.
- Alt, pada ponsel tanpa tombol Sym, seperti Unihertz Titan generasi pertama.

Jika Sym menjadi tombol SandFly, lapisan simbol keyboard tidak tersedia dari Sym. Pada Zinwa Q25, tombol berlabel Sym mengirimkan Alt Kanan. Pada BlackBerry KEY2, Fn adalah tombol Speed.

#### Setelan keyboard fisik di Mengetik {#keyboards-typing-settings}

**Mengetik** > **Keyboard fisik** ditampilkan saat keyboard fisik terhubung:

- **Tombol huruf menekan tombol keypad**: berlaku untuk keyboard yang tombol hurufnya juga memuat angka. Contohnya ponsel BlackBerry, Unihertz, dan Zinwa, yang tombol W, E, dan R-nya juga berarti 1, 2, dan 3. Tombol huruf menekan tombol di pad PIN layar kunci, keypad panggilan, dan kalkulator. Di keypad panggilan, nada keypad ikut diputar. Di kalkulator, karakter Alt dari huruf, seperti + dan -, menekan tombol operator. Di layar kunci, tombol angka juga menekan tombol pad PIN, sedangkan Enter dan Backspace menekan tombol Enter dan Hapus di pad tersebut. Huruf atau angka yang ditekan sebelum pad PIN tampil akan membuka pad PIN dan mengetikkan angkanya, atau membuka kunci perangkat jika PIN tidak diperlukan, seperti saat Extend Unlock membuat perangkat tetap tidak terkunci. Tombol dengan pengubah, tombol angka di luar layar kunci, dan tombol yang diketik ke kolom teks, seperti kolom sandi layar kunci, tidak diambil. Setelan ini aktif secara default, dan hanya ditampilkan untuk keyboard semacam itu.
- **Enter mengirim pesan**: di kolom pesan pada aplikasi perpesanan, seperti Messages, WhatsApp, Telegram, Signal, atau Slack, saat ada teks di dalamnya, Enter menekan tombol Kirim milik aplikasi. Shift + Enter dan Alt + Enter diteruskan ke aplikasi, yang mengetikkan baris baru. Saat navigasi tombol panah aktif, dan pada peta tombol ponsel berkeyboard, Enter pada kolom pesan yang baru dituju fokus SandFly tidak mengirim pesan sampai kolom tersebut diaktifkan atau diketik. Setelan ini bekerja dengan keyboard fisik apa saja, dan nonaktif secara default. Tombol Kirim pada ponsel berkeyboard, seperti tombol panggil hijau pada Zinwa Q25, menekan tombol Kirim di kolom pesan yang sama, baik setelan ini aktif maupun nonaktif. Di aplikasi tersebut, tombol ini juga menekan tombol Kirim yang ditampilkan di luar kolom, seperti tombol untuk pesan suara yang sedang direkam. Di tempat lain, tombol ini diteruskan ke ponsel seperti biasa.
- **Keyboard SandFly**: membuka daftar keyboard di setelan Android, tempat Anda mengaktifkan Keyboard SandFly. Lihat [](#keyboards-sandfly-keyboard).
- **Ketikan tombol yang ditahan**: karakter yang diketik saat tombol ditahan dengan Keyboard SandFly.
- **Karakter saat tombol ditekan dua kali**: karakter yang diketik saat tombol ditekan dua kali dengan Keyboard SandFly. Lihat [](#keyboards-double-press).
- **Spasi dua kali mengetikkan titik**: dengan Keyboard SandFly, Spasi yang ditekan dua kali setelah sebuah kata mengetikkan titik dan spasi. Nonaktif secara default.
- **Koreksi otomatis**, **Saran kata**, **Ucapkan saran**, **Enter mengetik saran yang diucapkan**, **Bahasa daftar kata**, dan **Hapus kata yang dipelajari**: koreksi dan saran untuk kata yang sedang diketik dengan Keyboard SandFly. **Koreksi otomatis** dan **Saran kata** nonaktif secara default. Lihat [](#keyboards-word-suggestions).
- **Ucapkan karakter sandi**: dengan Keyboard SandFly, di kolom sandi, SandFly mengucapkan setiap karakter yang diketik, dihapus, atau dilewati, alih-alih "butir". Nonaktif secara default. Lihat [](#keyboards-passwords).
- **Setelan keyboard fisik Android**: membuka setelan keyboard fisik Android, seperti tata letak keyboard.

### Keyboard SandFly {#keyboards-sandfly-keyboard}

Keyboard SandFly adalah metode input untuk keyboard fisik. Keyboard ini tidak menampilkan tombol apa pun di layar. Tombol tetap mengetik seperti tanpa keyboard ini. Keyboard SandFly menambahkan:

- Informasi pasti tentang apakah sebuah kolom teks menerima ketikan Anda. Dengan begitu, pintasan satu tombol dan Enter pada peta tombol ponsel berkeyboard bekerja di tempat yang tepat.
- Tombol yang ditahan untuk mengetikkan karakter Alt tombol tersebut atau huruf kapitalnya.
- Shift yang ditekan lalu dilepas sebelum sebuah tombol, sehingga tombol itu diketik dengan Shift, seperti di keyboard BlackBerry. Menekan dan melepas Shift sekali lagi sebelum tombol itu membatalkannya.
- Penekanan dua kali untuk mengetikkan karakter lain, seperti G G untuk ğ, dan titik untuk Spasi yang ditekan dua kali.
- Pencarian emoji dan daftar simbol.
- Mode pengeditan, tempat tombol tunggal memindahkan kursor serta memilih, menyalin, memotong, dan menempel.
- Koreksi otomatis dan saran kata.
- Karakter di kolom sandi, yang oleh Android hanya diberikan kepada pembaca layar sebagai butir.

Keyboard SandFly tidak tersedia di jam tangan dan TV.

#### Mengaktifkan Keyboard SandFly {#keyboards-turn-on-sandfly-keyboard}

1. Hubungkan keyboard, atau gunakan keyboard bawaan ponsel berkeyboard.
2. Di setelan SandFly, buka **Mengetik** > **Keyboard fisik** > **Keyboard SandFly**.
3. Aktifkan **Keyboard SandFly** di daftar keyboard.
4. Di kolom teks, beralih ke Keyboard SandFly dengan pengalih keyboard Android, atau dengan perintah **Ganti keyboard**. Perintah ini beralih ke keyboard aktif berikutnya. **Ganti keyboard** memerlukan Android 11 atau yang lebih baru.

Saat Keyboard SandFly digunakan, keyboard di layar tidak tampil.

#### Tombol yang ditahan {#keyboards-held-keys}

**Mengetik** > **Keyboard fisik** > **Ketikan tombol yang ditahan** mengatur karakter yang diketik saat Anda menahan tombol karakter dengan Keyboard SandFly:

- **Karakter Alt**: karakter Alt dari tombol tersebut, seperti di keyboard BlackBerry, atau huruf kapitalnya jika tombol itu tidak memiliki karakter Alt. Ini adalah default.
- **Huruf kapital**: huruf kapitalnya.
- **Karakter berulang**: karakter tersebut diulang, seperti tanpa Keyboard SandFly.

Tombol mengetikkan karakternya sendiri terlebih dahulu. Saat Android mulai mengulang karakter itu, Keyboard SandFly menggantinya dengan karakter untuk tombol yang ditahan.

#### Penekanan dua kali {#keyboards-double-press}

**Mengetik** > **Keyboard fisik** > **Karakter saat tombol ditekan dua kali** mencantumkan tombol dan karakter yang diketik saat tombol itu ditekan dua kali dengan Keyboard SandFly, seperti ğ untuk G, ö untuk O, atau ä untuk E. **Tambahkan tombol** menambahkan entri baru: masukkan karakter tombol di **Tombol**, dan 1 hingga 16 karakter di **Karakter saat ditekan dua kali**. Pilih tombol untuk **Edit** atau **Hapus**. Daftar ini kosong secara default.

Tekanan pertama mengetikkan karakter tombol tersebut. Jika Anda menekan tombol yang sama lagi dalam 350 milidetik, tanpa tombol lain atau perpindahan kursor di antaranya, karakter itu diganti dengan karakter tekan dua kali. Setelah huruf kapital, seperti dengan Shift, penekanan dua kali mengetikkan huruf kapitalnya, seperti Ğ. Tombol yang tidak ada di daftar mengetik seperti biasa.

Saat **Spasi dua kali mengetikkan titik** aktif, Spasi yang ditekan dua kali setelah huruf atau angka mengganti spasi pertama dengan titik dan spasi.

Penekanan dua kali tidak berlaku di kolom sandi.

#### Menelusuri emoji dan memilih simbol {#keyboards-emoji}

**Telusuri emoji** dan **Pilih simbol** membuka daftar di dalam kolom teks yang sedang diedit:

1. Jalankan **Telusuri emoji** atau **Pilih simbol**. SandFly mengucapkan "Pencarian emoji" atau "Simbol". Karakter yang terakhir Anda pilih muncul lebih dulu.
2. Ketik kata-kata dari nama karakter, seperti "jempol ke atas". Setiap kata yang Anda ketik harus cocok dengan awal salah satu kata dalam nama tersebut. Nama emoji mengikuti bahasa ponsel Anda.
3. Tekan tombol panah, atau Tab dan Shift + Tab, untuk berpindah melalui hasil yang cocok. SandFly membacakan setiap hasil beserta posisinya, seperti "1 dari 5".
4. Tekan Enter untuk mengetikkan karakter tersebut.

Backspace menghapus huruf terakhir yang diketik, dan menutup daftar jika belum ada yang diketik. Kembali atau Escape menutup daftar. Jika Keyboard SandFly tidak sedang digunakan di kolom teks, perintah ini mengucapkan "Memerlukan Keyboard SandFly di kolom teks".

Pada peta tombol ponsel berkeyboard, **Telusuri emoji** adalah Tombol SandFly + O, dan **Pilih simbol** adalah Alt + Spasi saat mengedit. Pada Zinwa Q25, Alt + Spasi juga membuka daftar simbol. Di peta tombol lain, Anda dapat menetapkannya di **Pintasan keyboard**, pada kategori **Pengeditan teks**.

#### Mode pengeditan {#keyboards-editing-mode}

**Aktifkan atau nonaktifkan mode pengeditan** mengaktifkan mode pengeditan di kolom teks yang sedang diedit. SandFly mengucapkan "Mode pengeditan aktif". Dalam mode pengeditan, tombol tunggal memindahkan kursor dan mengedit teks, bukan mengetik. SandFly membacakan setiap perpindahan:

- J dan L, atau Panah Kiri dan Panah Kanan: karakter sebelumnya dan berikutnya.
- I dan K, atau Panah Atas dan Panah Bawah: baris sebelumnya dan berikutnya.
- U dan O: kata sebelumnya dan berikutnya.
- Alt + J dan Alt + L: awal dan akhir baris. Alt + I dan Alt + K: awal dan akhir teks.
- T dan B: awal dan akhir teks.
- Home dan End: awal dan akhir baris. Dengan Ctrl: awal dan akhir teks.
- Shift bersama tombol perpindahan memilih teks. S memulai pemilihan, dan SandFly mengucapkan "Memilih". Tekan S lagi untuk berhenti.
- A memilih semua, C menyalin, X memotong, V menempel.
- Z mengurungkan, Shift + Z mengulangi.
- R membacakan pilihan, atau membacakan baris jika tidak ada yang dipilih.
- Tombol Delete menghapus.
- Enter, Escape, atau Kembali menonaktifkan mode pengeditan.

Tombol ketik lainnya tidak melakukan apa pun dalam mode pengeditan. Di kolom sandi, R mengucapkan "Tidak dibacakan di kolom sandi", dan C menyalin tanpa mengucapkan teksnya. Mode pengeditan memerlukan Keyboard SandFly. Pada peta tombol ponsel berkeyboard, pintasannya adalah Tombol SandFly + C.

#### Koreksi otomatis dan saran kata {#keyboards-word-suggestions}

Keyboard SandFly dapat mengoreksi kata yang Anda ketik dan menyarankan kata untuknya. Keduanya nonaktif secara default, di **Mengetik** > **Keyboard fisik**:

- **Koreksi otomatis**: saat Anda mengetik Spasi, tanda baca, atau Enter setelah kata yang salah eja, koreksinya menggantikan kata tersebut, dan SandFly mengucapkannya, seperti "receive, dikoreksi". Kata yang diawali huruf kapital di tengah kalimat, kata dengan huruf kapital setelah huruf pertama, dan kata yang diketik seluruhnya dengan huruf kapital dibiarkan seperti yang diketik. Dalam bahasa Inggris, i, im, dan dont menjadi I, I'm, dan don't.
- **Saran kata**: saat Anda mengetik kata, Panah Atas dan Panah Bawah berpindah di antara koreksi dan kata yang lebih panjang yang diawali teks yang Anda ketik, seperti "keyboard, 1 dari 8" untuk "keyb". Di Zinwa Q25, trackpad mengirim tombol-tombol ini. Enter, atau klik trackpad, mengetikkan saran disertai spasi; Spasi atau tanda baca mengetikkannya diikuti karakter tersebut. Kembali atau Escape menutup daftar dan mempertahankan kata seperti yang diketik. Tombol lain menutup daftar dan menjalankan fungsinya, sehingga Backspace menghapus huruf dan huruf diketik. Saat tidak ada kata yang sedang diketik, setelah Spasi, tanda baca, atau perpindahan kursor, Panah Atas dan Panah Bawah berpindah di dalam teks seperti sebelumnya.

**Ucapkan saran**: saat Anda mengetik kata, keyboard mengucapkan dengan nada lebih rendah koreksi yang akan diketik Spasi, seperti "receive, koreksi", atau jika tidak ada, saran kata pertama, seperti "keyboard" untuk "keyboa". Lanjutkan mengetik untuk mempertahankan kata, tekan Panah Bawah untuk saran lain, atau Spasi untuk mengambil koreksi. Tombol berikutnya menghentikan ucapan ini. Pilih kapan saran diucapkan:

- **Segera**: setelah setiap tombol, tepat setelah gema keyboard untuk tombol tersebut, atau langsung jika gema keyboard nonaktif.
- 0,25 hingga 3 detik: saat Anda berhenti mengetik di dalam kata selama waktu tersebut. Default-nya adalah 1 detik.
- **Nonaktif**: tidak pernah.

Setelan ini berlaku saat **Koreksi otomatis** atau **Saran kata** aktif.

**Enter mengetik saran yang diucapkan**, nonaktif secara default: setelah koreksi atau saran diucapkan, Enter mengetikkannya disertai spasi, hingga Anda melanjutkan mengetik atau memindahkan kursor. Di Zinwa Q25, klik trackpad mengirim Enter, sehingga klik mengetikkan saran tersebut. Enter kedua diteruskan ke aplikasi, misalnya untuk mengirim pesan. Panah Bawah kemudian membuka daftar pada saran setelah saran yang diucapkan. Jika sakelar nonaktif, Enter diteruskan ke aplikasi seperti sebelumnya, Panah Bawah pertama membuka daftar pada saran pertama, dan Panah Atas pertama pada saran terakhir.

Geseran trackpad mengirim dua tekanan tombol panah atau lebih; di dalam daftar, tekanan ke arah yang sama dengan selang kurang dari 0,1 detik hanya berpindah satu kali.

Untuk membatalkan koreksi, tekan Backspace tepat setelahnya. SandFly mengucapkan kata seperti yang Anda ketik, seperti "recieve, koreksi dibatalkan", dan kata itu tidak pernah dikoreksi lagi.

Kata yang Anda ketik dan pilih mendapat peringkat lebih tinggi dalam saran. Kata yang dipelajari ini, serta kata yang koreksinya Anda batalkan, hanya disimpan di ponsel, untuk setiap bahasa. **Hapus kata yang dipelajari** menghapusnya. Tidak ada yang dipelajari di kolom sandi atau di kolom yang menonaktifkan pembelajaran, seperti penjelajahan pribadi.

**Bahasa daftar kata** mengatur bahasa kata: **Bahasa sistem** (default), atau salah satu dari bahasa Inggris (AS), Inggris (Inggris Raya), Jerman, Spanyol, Prancis, Portugis (Brasil), Portugis (Portugal), Hungaria, Turki, Rusia, Ukraina, dan Arab, masing-masing dicantumkan dengan namanya sendiri, seperti Deutsch. Tanpa daftar kata untuk bahasa sistem, tidak ada yang dikoreksi atau disarankan hingga Anda memilih salah satunya. Koreksi memperhitungkan tombol tata letak keyboard Anda: huruf yang diketik untuk tombol di sebelahnya dikoreksi lebih dulu. Huruf yang diketik tanpa aksennya, seperti fur untuk für, juga dikoreksi.

Koreksi otomatis dan saran kata tidak digunakan di kolom sandi, alamat email, alamat web, dan angka, maupun di kolom yang ditandai tanpa saran.

Tanpa tombol panah, gunakan perintah **Saran kata berikutnya**, **Saran kata sebelumnya**, dan **Ketik saran kata**, di kategori **Pengeditan teks**. Perintah ini tidak memiliki pintasan default: tetapkan di **Pintasan keyboard**, tempat **Hanya saat mengedit** mempertahankan tombol untuk mengetik di tempat lain, atau tetapkan ke gerakan. **Ketik saran kata** mengetikkan saran yang terakhir diucapkan, atau saran pertama untuk kata yang diketik. Dengan sentuhan, tambahkan kontrol pembacaan **Saran kata**, di grup **Tindakan untuk item saat ini** pada **Kontrol pembacaan**: saat kata sedang diketik, geser ke atas atau ke bawah untuk berpindah di antara saran, lalu ketuk dua kali untuk mengetikkan saran yang diucapkan SandFly. Kontrol pembacaan ini nonaktif secara default dan memerlukan Android 11 atau yang lebih baru.

#### Kolom sandi {#keyboards-passwords}

Untuk teks di kolom sandi, Android hanya memberikan butir kepada pembaca layar, sehingga SandFly mengucapkan "butir" untuk setiap karakter. Keyboard SandFly dapat membaca teks dari kolom tempatnya mengetik, sehingga SandFly dapat mengucapkan karakternya dengan dua cara.

**Mengetik** > **Keyboard fisik** > **Ucapkan karakter sandi**, nonaktif secara default: di kolom sandi yang sedang diedit dengan Keyboard SandFly, SandFly mengucapkan:

- Setiap karakter yang diketik, seperti "huruf kapital P", "di", atau "1". Karakter dinamai seperti di kolom teks lain, dan huruf kapital mengikuti **Panjang respons** > **Huruf kapital**.
- Setiap karakter yang dihapus dengan Backspace atau Delete, seperti "a dihapus".
- Karakter yang dilewati kursor dengan Panah Kiri atau Panah Kanan, trackpad, atau mode pengeditan.
- Untuk tombol yang ditahan agar mengetik karakter Alt-nya, karakter tersebut dan karakter yang digantikannya, seperti "di menggantikan a".

Teks yang ditempel atau diisi otomatis, kolom yang dikosongkan, pilihan, dan perpindahan melewati lebih dari satu karakter diucapkan seperti sebelumnya, dengan butir.

**Eja kolom sandi**, di kategori perintah **Pengeditan teks**, mengeja seluruh teks kolom sandi yang sedang diedit, setiap karakter beserta posisinya, seperti "1 huruf kapital P, 2 a, 3 di, 4 1". Huruf kapital selalu diucapkan sebagai "huruf kapital". Perintah ini bekerja baik **Ucapkan karakter sandi** aktif maupun nonaktif. Di kolom teks yang bukan kolom sandi, perintah ini mengucapkan "Bukan kolom sandi". Jika Keyboard SandFly tidak digunakan di kolom teks, perintah ini mengucapkan "Memerlukan keyboard SandFly di kolom teks". Pada peta tombol ponsel berkeyboard, pintasannya adalah Tombol SandFly + Y. Di peta tombol lain, tetapkan di **Pintasan keyboard**. Anda juga dapat menetapkannya ke gerakan atau menambahkannya ke menu SandFly.

Karakter sandi hanya diucapkan dengan dua cara ini. Karakter tersebut tidak disimpan untuk **Ulangi frasa yang terakhir diucapkan**, **Eja frasa yang terakhir diucapkan**, **Salin frasa yang terakhir diucapkan**, atau **Histori ucapan**, dan log SandFly hanya mencatat jumlah karakter di dalam kolom.

Kolom teks bawaan Android memberikan teksnya kepada Keyboard SandFly, demikian pula sebagian besar aplikasi. Jika aplikasi tidak memberikannya, SandFly mengucapkan "butir" seperti sebelumnya, dan **Eja kolom sandi** mengucapkan "Teks kolom sandi tidak tersedia".

### Setelan keyboard lainnya {#keyboards-other-settings}

- **Mengetik** > **Gema keyboard** > **Keyboard fisik** mengatur apa yang diucapkan SandFly saat Anda mengetik di keyboard fisik. Lihat [](#typing).
- Setiap tombol pada keyboard fisik menghentikan ucapan, kecuali tombol pengubah seperti Shift, Caps Lock, Num Lock, Scroll Lock, dan tombol volume. **Ucapan** > **Hentikan ucapan saat mengetik** mengatur kapan karakter yang diketik menghentikan ucapan, dan **Ucapan** > **Hentikan ucapan saat menekan Enter** mengatur apakah Enter menghentikannya. Ctrl yang ditekan sendirian menjeda atau melanjutkan ucapan. Lihat [](#speech-stop).
- Jika keyboard fisik terhubung saat SandFly pertama kali dimulai, yang terbuka adalah tutorial keyboard, bukan tutorial gerakan sentuh. Saat Anda membuka tutorial di lain waktu dengan keyboard terhubung ke perangkat berlayar sentuh, SandFly menawarkan **Tutorial gerakan sentuh** dan **Tutorial keyboard**. Lihat [](#getting-started).
