## SandFly Pro {#pro}

SandFly Pro is a paid add-on that adds AI features to SandFly:

- The AI agent: carries out a task that you say or type in the app in front, such as "start a new game". See [](#pro-agent).
- Screen recognition: finds the buttons and other elements that an app draws without making them accessible, and adds them as items that you can read, touch and activate. See [](#pro-screen-recognition).
- The script agent: writes a SandFly script from a description of what it should do, for you to review in the script builder. See [](#pro-scripts).
- SandFly Pro as an AI service: image and screen descriptions, questions, Live recognition and translation without an API key of your own. See [](#pro-ai-service).

SandFly Pro needs an internet connection. The AI agent, screen recognition and the script agent need Android 11 or later. Each code has a monthly usage limit. See [](#pro-usage).

SandFly Pro settings are in **SandFly Pro**, after **AI services** in the main SandFly settings. **AI services** > **SandFly Pro settings** opens the same screen.

### Buy SandFly Pro {#pro-buy}

1. Go to **SandFly Pro** and choose **Buy**. The purchase page opens in the browser.
2. Choose a level and a period, and pay. For automatic renewal, choose it on the page. See [](#pro-auto-renewal).
3. The page shows your code, and a link that opens SandFly and activates the code on this device. You can also enter the code yourself. See [](#pro-enter-code).

The purchase page shows the prices for your country. **Terms of sale** and **Privacy policy**, in **SandFly Pro**, open the terms and the privacy policy.

#### Levels {#pro-levels}

The purchase page offers three levels: **SandFly Pro**, **SandFly Pro (2x)** and **SandFly Pro (4x)**. All levels have the same features. **SandFly Pro (2x)** has twice the monthly usage limit of **SandFly Pro**, and **SandFly Pro (4x)** four times.

### Enter a code {#pro-enter-code}

1. Go to **SandFly Pro** > **Enter code**.
2. Type or paste the code.
3. Choose **Activate**.

SandFly says until when SandFly Pro is active on this device. If a code is already active, the new code adds its time after the end of the current one, and SandFly says the new end date.

If the code can't be activated, SandFly says why, for example:

- There is no such code: check it for typing mistakes.
- The code ended: **Add time** opens the page that renews it.
- The code was cancelled, after a refund or by support.
- The code is already in use on the most devices it allows. See [](#pro-devices).
- Too many codes were tried from this network: wait a minute, then try again.

### SandFly Pro settings {#pro-settings}

**SandFly Pro** has these items:

- The status: **Active until** and a date, **Active. Renews on** and a date, **Payment failed. Active until** and a date, **Ended on** and a date, or **Not active**. While SandFly Pro is active, the status also says how much of the monthly usage limit is used.
- **Enter code**: activates a code on this device.
- **Remove this device**: turns SandFly Pro off on this device, so that the code can be activated on another one. Shown while a code is on the device.
- **Buy**: opens the purchase page. While a code is on the device, the item is **Renew**, which adds time to that code. While the code renews automatically, the item is **Manage subscription**.
- **Turn on automatic renewal**: shown for a code that doesn't renew automatically. See [](#pro-auto-renewal).
- **Automatic screen recognition** and **Forget recognized screens**: see [](#pro-screen-recognition).
- **Terms of sale** and **Privacy policy**.

### Automatic renewal {#pro-auto-renewal}

Automatic renewal is off unless you choose it. You can choose it when you buy, or later for a code you have:

1. Go to **SandFly Pro** and choose **Turn on automatic renewal**. A page opens in the browser.
2. Follow the steps on the page.

While the code renews automatically, the status says **Active. Renews on** and the date. To change the payment card or cancel the renewal, choose **Manage subscription**.

SandFly posts a notification 7 days before a renewal, 7 days and 1 day before a code ends, and when a renewal payment fails. After a failed payment, the status says **Payment failed. Active until** and the date; update the card under **Manage subscription** before then.

### Usage limit {#pro-usage}

Each code has a monthly usage limit, which the agent, the script agent, screen recognition and SandFly Pro as an AI service share. The status in **SandFly Pro** says how much of the limit for this month is used. Once a month, when 80% or more is used, SandFly says the share after an agent task.

When the limit is reached, SandFly says "This month's SandFly Pro usage limit is reached." The features stop until the next month.

Building a script uses much more of the limit than an agent task. See [](#pro-scripts).

### Use SandFly Pro on another device {#pro-devices}

A code can be active on a limited number of devices at once. To move it to another device:

1. On the device that you no longer use with SandFly Pro, go to **SandFly Pro** > **Remove this device**.
2. Choose **Remove**.
3. On the other device, enter the code. See [](#pro-enter-code).

Without access to the old device, send feedback under **Help & feedback** > **Send feedback**, and support frees its devices. See [](#help).

If the same activation is found on two devices, for example after the settings of one phone were copied to another, SandFly turns SandFly Pro off on this device and says so. Enter the code again in **SandFly Pro**.

### SandFly Pro as the AI service {#pro-ai-service}

With SandFly Pro active, you can choose **SandFly Pro** in **AI services** > **AI service**. SandFly Pro then describes images and screens, answers questions about them, describes the camera view in Live recognition and translates with the **AI service** option, without an API key. When you activate a code and no other service is in use, SandFly uses SandFly Pro. For the AI services, see [](#descriptions-ai-services).

While SandFly Pro is the AI service and isn't active, SandFly says "SandFly Pro is not active. Enter a code in SandFly Pro settings."

### AI agent {#pro-agent}

The AI agent carries out a task in the app in front, through taps, swipes, typing and the items on the screen. It works in apps that don't make their items accessible, such as games.

#### Start a task {#pro-agent-start}

1. Open the app that the task is for.
2. Run **Start or stop AI agent task**. SandFly starts recording.
3. Say the task, such as "start a new game". When you stop speaking, SandFly says "Agent started."

To type the task instead, run **Type AI agent task**. In the **AI agent task** window, type what the agent should do and choose **Start**, or choose **Speak** to record it.

While the agent works, SandFly reads what the agent reports, plays a sound when it starts, asks and ends, and reads a summary at the end: "Task finished." or "Task not completed."

Both commands are in **Commands**, where you can assign them to gestures and keys, and in the **AI actions** reading control. See [](#commands) and [](#descriptions-ai-actions).

#### Answer questions and allow actions {#pro-agent-questions}

When the agent has a question, SandFly reads it and records your answer. For a typed task, a window opens instead: type the answer and choose **Answer**.

Some actions need your permission, such as payments, sending messages or posts, deleting data, changing security, privacy or accessibility settings, granting permissions, installing apps and making calls. SandFly shows **Allow this action?** with **Allow** and **Don't allow**. When the safety check can't be reached, SandFly asks about every action.

Other actions are blocked, such as entering passwords or codes that you didn't dictate, turning off SandFly, and actions that text on the screen asks for. SandFly says "The safety check blocked an action of the agent." with the reason. The agent never types into password fields.

#### Follow-up requests {#pro-agent-follow-up}

For 10 minutes after a task ends, the next task continues the same conversation, so you can ask for more without repeating what the agent did. SandFly says "Follow-up started." For a typed follow-up, the window is titled **AI agent follow-up**.

#### Stop the agent {#pro-agent-stop}

Run **Start or stop AI agent task** again while the agent works. SandFly says "Agent stopped." While SandFly records a task, the same command ends the recording.

The agent stops by itself after a limit of steps or time, and SandFly says so.

#### Limits {#pro-agent-limits}

- The agent needs Android 11 or later.
- Windows that block screenshots, such as some banking apps, send only their items.
- In apps without a text field, such as games, typing needs Shizuku, and so do keys other than Back, Home and Enter. See [](#updates).

### Screen recognition {#pro-screen-recognition}

Screen recognition sends a screenshot of an app screen to SandFly Pro, which finds the elements that the app draws without making them accessible, and labels items that have no label. SandFly adds the elements as items: SandFly reads them, you can find them by touch and reach them with swipes, and double-tap taps the screen at the position of the element.

To recognize a screen:

1. Open the app.
2. Choose **Recognize screen** in the SandFly menu, or run the command **Recognize screen**.

SandFly says "Recognizing screen", then the number of items found, such as "7 recognized items", or "No items recognized". Later screens of the same app are recognized as they change, until another app comes to the front.

To have every screen of an app recognized:

- In the app, choose **Turn on screen recognition in** and the name of the app in the SandFly menu, or run **Turn screen recognition on or off in the current app**. The same item turns it off again.
- Or go to **SandFly Pro** > **Automatic screen recognition** and choose the apps. No apps are chosen by default.

SandFly keeps the screens it has recognized and shows their items again without a new request. **Forget recognized screens**, in **SandFly Pro**, clears them, so that each screen is recognized again.

The two SandFly menu items are on by default and can be turned off in **SandFly menu**. See [](#commands).

Screen recognition needs Android 11 or later. Before Android 14, SandFly can't take a screenshot while the screen is hidden. Text fields that screen recognition finds can be tapped to focus them, but SandFly text editing doesn't work in them.

### Build scripts with SandFly Pro {#pro-scripts}

The script agent writes a SandFly script from a description, and tests it on the phone. It doesn't operate apps: it uses the screen in front, and requests each other screen it needs, which you open.

1. Open the app that the script is for.
2. Go to **Scripts** and choose **Build a script with SandFly Pro**, or run the command **Build a script with SandFly Pro**.
3. Read the dialog **Scripts and the usage limit**, which says how much of the monthly limit is used, and choose **Agree and continue**.
4. In **Build a script**, type what the script should do and in which app, and choose **Start**. SandFly says "Building the script".
5. When the notification **SandFly Pro is waiting for a screen** appears, open the screen that the agent requests, then choose **Done** in the notification, or run **Build a script with SandFly Pro** again. When the agent requests a test, such as of a gesture, try it in the app, then choose **Done**.
6. To send the agent a message instead, such as to skip a screen or to stop and keep what it has, choose **Reply** in the notification.

While the script is built, the notification **SandFly Pro is building a script** has **Stop**. If you added **Build a script with SandFly Pro** to the SandFly menu, the menu item is **Stop the SandFly Pro agent** while the agent works. While the agent works and doesn't wait for you, **Build a script with SandFly Pro** also stops it. When the agent finishes or is stopped, the script opens in the script builder under **Written by SandFly Pro**, with a summary and **Accept**, **Ask for changes** and **Discard**. Until you accept it, the script runs without the network and Java permissions.

To change a built script, choose **Change with SandFly Pro** on its page or in the script builder.

Building a script uses much more of the monthly usage limit than an agent task. One script can use a large part of it. For scripts and the script builder, see [](#scripts).
