## Voice commands {#appendix-voice-commands}

These are the English phrases that SandFly accepts as voice commands. Words in capitals stand for what you say in their place, such as a name or a text. Words in parentheses are optional, and a slash separates words that can take each other's place: "describe (the/this) image" is "describe image", "describe the image" or "describe this image". Case and the punctuation that the speech recognizer adds don't matter. For how to start a voice command, chain commands and make your own phrases, see [](#voice-commands).

Besides these phrases, you can say the name of any command as the **Commands** screen shows it, such as "Read from top", "Next item" or "Describe image", including the names of macros, custom menus and script commands. Custom voice commands come before every phrase here. See [](#voice-commands-phrases).

Some phrases are found anywhere in what you say: they are marked "a phrase with". For example, "go to the top" contains "top" and moves to the first item.

### Navigation {#appendix-voice-commands-navigation}

| Say | What happens |
| --- | --- |
| "Next heading" | Moves to the next heading. |
| "Next control" | Moves to the next control. |
| "Next link" | Moves to the next link. |
| "Next landmark" | Moves to the next landmark on a web page. |
| A phrase with "first" or "top" | Moves to the first item on the screen. |
| A phrase with "last" or "bottom" | Moves to the last item on the screen. |
| "Find TEXT", or "search for TEXT" or "search TEXT" | Moves to the first item on the screen that includes the text. |
| "Find" | Moves to the next item that includes the text of the last search. |
| "Screen search", or "search on screen" | Opens screen search. |
| "Actions", or "custom actions" or "action" | Opens the **Actions** menu of the focused item. |

### Reading {#appendix-voice-commands-reading}

| Say | What happens |
| --- | --- |

| "Read from focused item", or "read from cursor" | Reads the screen from the focused item. |
| "Copy last spoken phrase" | Copies the last phrase that SandFly spoke. |

### Text editing {#appendix-voice-commands-text-editing}

These phrases act on the focused edit field.

| Say | What happens |
| --- | --- |
| "Type TEXT", or "write TEXT", "enter TEXT", "input TEXT", "dictate TEXT" or "spell TEXT" | Types the text. |
| "New line", or "new paragraph" or "press enter" | Types a new line in a text field of several lines, or performs the action of a field of one line. |
| "Select all" | Selects all the text. |
| "Select", or "start select", "start selection" or "start selection mode" | Starts selection mode. |
| "Finish select", or "finish selection", "finish selection mode" or "end select" | Ends selection mode. |
| A phrase with "copy" | Copies the selected text. |
| A phrase with "cut" | Cuts the selected text. |
| A phrase with "paste" | Pastes the clipboard. |
| A phrase with "delete" | Deletes the selected text. |

### Speech {#appendix-voice-commands-speech}

| Say | What happens |
| --- | --- |
| A phrase with "faster", such as "speak faster", or "increase speech rate" | Raises the speech rate. |
| A phrase with "slower", such as "speak slower", or "decrease speech rate" | Lowers the speech rate. |
| A phrase with "language" or "languages" | Opens the list of spoken languages. |

| Say | What happens |
| --- | --- |
| A phrase with "home" or "desktop" | Goes to the home screen. |
| "Back", or "go back" | Goes back. |
| A phrase with "notification" or "notifications" | Opens the notifications. |
| "Quick Settings", or "quick setting" | Opens Quick Settings. |
| A phrase with "apps", without "recent" or "recents" | Opens all apps, on devices that support it. |

### SandFly {#appendix-voice-commands-sandfly}

| Say | What happens |
| --- | --- |
| "SandFly settings", or "SandFly setting", "TalkBack settings" or "TalkBack setting" | Opens SandFly settings. |
| "Hide screen", or a phrase with "dim" or "darken" | Hides the screen. |
| "Show screen", or "brighten screen", "restore screen" or "cancel hide screen" | Shows the screen again. |
| "Label TEXT" | Gives the focused item the custom label. SandFly says "Label saved". |
| A phrase with "help", or with "what" and "say", such as "What can I say" | Opens **Voice command overview**. |
| "Cancel", "never mind", "nevermind" or "shut up", or a phrase with "stop", "quit", "quiet" or "pause" | Stops the voice command that is running. |

### Apps, items and commands {#appendix-voice-commands-apps}

| Say | What happens |
| --- | --- |
| "Open APP", or "launch APP", "start APP" or "switch to APP" | Opens the app. |
| "Tap ITEM", or "tap on ITEM", "double tap (on) ITEM", "click (on) ITEM", "press ITEM", "activate ITEM" or "select ITEM" | Activates the item on the screen with that text. |
| "Run COMMAND", or "do COMMAND" | Runs the command, macro or script command with that name. |
| "Run (the) NAME macro", or "run (the) macro NAME" | Runs the macro. |
| "Wait", or "wait (a) second" | Waits 1 second. |
| "Wait NUMBER seconds", or "wait NUMBER second" | Waits the number of seconds, up to 60. |

### Calls and messages {#appendix-voice-commands-calls}

NAME is a contact name or a phone number. APP is the name of a messaging app, such as WhatsApp. Without an app, or with "SMS", "text", "text message" or "messages", the message goes to the default SMS app. In the SMS app and WhatsApp, SandFly writes the message to the contact and then asks whether to send it. Other apps get only the text, and you choose the chat in the app.

| Say | What happens |
| --- | --- |
| "Call NAME", or "phone NAME", "ring NAME", "dial NAME" or "make a call to NAME" | Calls the contact or number. |
| "Message NAME saying TEXT", or "text NAME saying TEXT", "send (a) message to NAME saying TEXT", "send (a) message to NAME that says TEXT" or "send NAME (a) message saying TEXT" | Writes the message. |
| "Message NAME TEXT", or "text NAME TEXT" or "send (a) message to NAME TEXT" | Writes the message to the contact named at the start. |
| "Message NAME on APP saying TEXT", or "send (a) message to NAME on APP saying TEXT", "send (a) message to NAME on APP that says TEXT", "send (a/an) APP message to NAME saying TEXT", "send (a/an) APP message to NAME that says TEXT" or "tell NAME on APP TEXT" | Writes the message in the app. |
| "Send (a/an) APP message to NAME" | Records the text, then writes the message in the app. |

SandFly asks "Send to NAME: TEXT?", or "Send to NAME?" for a description. Say "yes", "yeah", "yep", "send", "send it", "OK", "okay", "sure" or "do it" to press **Send**. Any other answer leaves the message unsent, and SandFly says "Message not sent".

### Descriptions {#appendix-voice-commands-descriptions}

| Say | What happens |
| --- | --- |
| "Describe (the) screen", or "describe what's on (the) screen", "what's on (the/my) screen" or "what is on (the/my) screen" | Reads a description of the screen. |
| "Describe (the/this) image", or "describe (the/this) picture", "describe (the/this) photo", "what's in (the/this) image", "what's in (the/this) picture" or "what's in (the/this) photo" | Reads a description of the focused image. |
| "Copy it", or "copy that", "copy the description", "copy what you (just) said", "copy (the) last spoken (phrase)", "copy (the) last phrase" or "copy (the) last thing said" | Copies the description from the command before, or else the last phrase that SandFly spoke. |
| "Send it to NAME", or "send that to NAME", "send the description to NAME", "share it with NAME" or "send it to NAME on APP" | Sends the description from the command before, or else the last phrase that SandFly spoke, as a message. |
| "Send (the/an) image description to NAME", or "send (a) description of (the/this) image to NAME", "send (the/a) picture description to NAME", "send (a) description of (the/this) picture to NAME" or "send (a/the) photo description to NAME" | Describes the focused image and sends the description as a message. |
| "Send (the/a) screen description to NAME", or "send (a) description of (the) screen to NAME" | Describes the screen and sends the description as a message. |

### Chains and other words {#appendix-voice-commands-chains}

| Say | What happens |
| --- | --- |
| "then", or "and then", "after that" or "afterwards", between commands | Runs the commands one after another, such as "open Messages then call Sam". |
| "and", between commands | Runs the commands one after another when each part is a command, such as "go home and open Chrome". |
| "please", "can you", "could you", "would you", "I want to", "I'd like to" or "now", at the start | Left out. |
| "please", "for me" or "now", at the end | Left out. |
